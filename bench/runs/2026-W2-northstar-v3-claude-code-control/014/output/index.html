该选哪一种？

不确定的话，先上一节体验课，顾问会根据测评结果给出建议。

适合一对一，如果你……

  • 有明确目标：雅思口语、面试、出差汇报
  • 时间不固定，需要随时约课
  • 害羞或基础薄弱，想在无压力环境下开口
  • 希望老师逐句纠正发音和语法

适合小班课，如果你……

  • 想用更低预算保持长期练习
  • 喜欢和同学讨论、角色扮演
  • 需要固定课表和同伴来督促自己
  • 想练习多人对话中的倾听与回应

常见问题

还有其他疑问？欢迎联系在线客服。

课时包可以退款吗？

购买后 7 天内且未上课，可全额退款。超过 7 天，按已上课时的原价扣除后退还剩余费用。

一对一和小班课的课时可以互换吗？

可以。1 节一对一课时可兑换 2 节小班课，需在课时有效期内联系学习顾问办理。

小班人数不满怎么办？

小班最少 3 人开班。若开班时人数不足，我们会为你调到同级别的其他班级，或全额退款。

课时包过期了怎么办？

有效期到期前可申请一次免费延期 1 个月；冲刺包和年度班可延期 3 个月。

支持分期付款吗？

进阶包、冲刺包、季度班和年度班支持 3 / 6 / 12 期分期，部分渠道免息。

需要准备什么设备？

电脑、平板或手机均可上课，建议使用耳机麦克风，网络带宽 2 Mbps 以上即可。
