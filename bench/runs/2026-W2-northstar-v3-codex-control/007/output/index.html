LESS MANUAL. MORE MEANINGFUL.

每到月底，都要打开十几个 Excel 文件，筛选、求和、调格式，再重复一遍？这些工作，Python 可以帮你接手。

这篇文章用一份销售明细作为例子，串起 读取 → 清洗 → 汇总 → 美化 → 批量处理 的完整流程。每一个技巧都配有代码，你可以从最需要的那一步开始。

⌘
开始之前

示例使用 Python 3、pandas 和 openpyxl。请在你的 Python 环境中准备好这两个库：

pip install pandas openpyxl

示例文件：sales.xlsx · 工作表：销售明细 · 字段：订单号、日期、地区、产品、销售额

01
READ WITH INTENTION

精准读取，只取需要的数据

别急着把整张工作表搬进内存。用 sheet_name 指定工作表，用 usecols 选择字段，并在读取时为订单号指定字符串类型，避免丢失前导零。

01_read.py
import pandas as pd

# 订单号应在源文件中以文本存储，例如 "00128"
df = pd.read_excel(
    "sales.xlsx",
    sheet_name="销售明细",
    usecols=["订单号", "日期", "地区", "产品", "销售额"],
    dtype={"订单号": "string"},
    engine="openpyxl",
)

print(df.head())
↳

一个小细节　如果 Excel 中的前导零仅来自显示格式，dtype 无法恢复它。已知订单号固定为 5 位时，可再用 .str.zfill(5) 补齐。

02
MAKE DATA RELIABLE

先清洗，再开始计算

多余空格、文本金额、重复行，往往是报表数字对不上的原因。先统一格式，再把无效数据单独保存，后面的汇总才有可靠的基础。

02_clean.py
# 接续上一步的 df；只删除整行完全相同的记录
df = df.drop_duplicates().copy()
for col in ["地区", "产品"]:
    df[col] = df[col].astype("string").str.strip()
    df[col] = df[col].replace("", pd.NA)

amount = df["销售额"].astype("string").str.replace(",", "", regex=False)
df["销售额"] = pd.to_numeric(amount, errors="coerce")
df["日期"] = pd.to_datetime(df["日期"], errors="coerce")

invalid = df[["日期", "地区", "产品", "销售额"]].isna().any(axis=1)
df.loc[invalid].to_excel("待核对.xlsx", index=False)
clean = df.loc[~invalid].copy()
↳

别急着填 0　缺失金额不等于零收入。保留异常记录，核对后再补充；日期列应为 Excel 日期或可解析文本，纯数字日期序号需要另外转换。

03
FIND THE BIG PICTURE

用透视表，一次完成分类汇总

想知道各地区每类产品卖了多少？pivot_table 就是代码里的数据透视表。只需指定行、列和聚合方式，明细便能变成一目了然的交叉报表。

03_summarize.py
summary = clean.pivot_table(
    index="地区",
    columns="产品",
    values="销售额",
    aggfunc="sum",
    fill_value=0,
    margins=True,
    margins_name="总计",
)
summary.to_excel("地区销售汇总.xlsx")

让口径保持一致　这里的空组合填 0，表示清洗后的数据中没有对应销售记录。源数据中的无效金额，已在上一步单独隔离。

04
READY TO SHARE

自动美化，让报表开箱即用

数据算对了，交付也要顺手。借助 openpyxl 设置表头、列宽和金额格式，再冻结首行首列，让同事打开文件就能开始阅读。

04_format.py
from openpyxl import load_workbook
from openpyxl.styles import Font, PatternFill
from openpyxl.utils import get_column_letter

wb = load_workbook("地区销售汇总.xlsx")
ws = wb.active
ws.freeze_panes = "B2"

for cell in ws[1]:
    cell.font = Font(bold=True, color="FFFFFF")
    cell.fill = PatternFill("solid", fgColor="7560C5")

for col in range(1, ws.max_column + 1):
    ws.column_dimensions[get_column_letter(col)].width = 18
for row in ws.iter_rows(min_row=2, min_col=2):
    for cell in row:
        cell.number_format = '#,##0.00'

wb.save("地区销售汇总_交付版.xlsx")
↳

数值与显示分开　数字格式只改变显示方式，不会把金额转成文本。这样，接收报表的人依然可以继续计算。

05
DO IT ONCE, SCALE IT UP

批量合并，把重复工作交给循环

当各区域的文件格式一致，就不用逐个打开。把原始文件放进 data/，统一读取并加上来源文件名，再一次导出；之后可复用前面的清洗和汇总流程。

05_batch.py
from pathlib import Path
import pandas as pd

files = sorted(
    p for p in Path("data").glob("*.xlsx")
    if not p.name.startswith("~$")
)
if not files:
    raise FileNotFoundError("data 目录中没有可合并的文件")

frames = []
for path in files:
    part = pd.read_excel(
        path, sheet_name="销售明细", dtype={"订单号": "string"}
    )
    part["来源文件"] = path.name
    frames.append(part)

merged = pd.concat(frames, ignore_index=True)
# 输出到原始文件目录之外，避免下次重复合并
with pd.ExcelWriter("合并报表.xlsx", engine="openpyxl") as writer:
    merged.to_excel(writer, sheet_name="全部明细", index=False)
↳

保留数据的来处　“来源文件”列能帮你追溯异常。正式合并前，确认各文件的字段、单位和日期范围一致，并排除 Excel 自动生成的 ~$ 临时文件。
