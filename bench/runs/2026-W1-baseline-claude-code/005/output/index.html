科室介绍

按需挂号，不确定看哪科，打电话问前台就行。

  1. 内科

    呕吐、腹泻、咳嗽、皮肤病等常见病诊疗，慢性肾病与糖尿病长期随访。

  2. 外科

    软组织手术、骨科固定、肿物切除。独立无菌手术室，术中全程麻醉监护。

  3. 猫科门诊

    猫咪专属候诊区与诊室，与狗狗分开，减少应激。擅长泌尿与口炎问题。

  4. 牙科

    超声洁牙、拔牙、口腔 X 光检查。三岁以上建议每年检查一次口腔。

  5. 影像检验

    数字 X 光、B 超、血常规与生化，大部分检验结果三十分钟内出具。

  6. 预防保健

    疫苗、驱虫、绝育、芯片植入与体检套餐，幼宠与老年宠分别定制方案。
