用户服务 API 文档

本文档介绍用户服务的鉴权方式以及用户相关的四个 REST 接口。所有请求与响应均使用 JSON 格式，字符编码为 UTF-8。

Base URLhttps://api.example.com/v1
Content-Typeapplication/json
时间格式ISO 8601，UTC，例如 2026-10-25T08:30:00Z
限流每个 Token 每分钟 600 次请求，超出返回 429，响应头 Retry-After 给出等待秒数

鉴权方式

API 使用 Bearer Token（OAuth 2.0 Client Credentials） 鉴权。先用控制台分配的 client_id 与 client_secret 换取访问令牌，再在每个请求的 Authorization 请求头中携带该令牌。

1. 获取访问令牌

POST /oauth/token
参数类型必填说明
grant_typestring必填固定为 client_credentials
client_idstring必填应用 ID
client_secretstring必填应用密钥
scopestring可选以空格分隔的权限范围，如 users:read users:write；缺省为应用拥有的全部权限
请求示例 
curl -X POST https://api.example.com/v1/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "client_credentials",
    "client_id": "app_7f3k2m",
    "client_secret": "sk_live_xxxxxxxxxxxxxxxx",
    "scope": "users:read users:write"
  }'
响应示例 · 200 OK 
{
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 7200,
  "scope": "users:read users:write"
}

2. 携带令牌调用接口

请求头 
Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...

权限范围（Scope）

Scope说明适用接口
users:read读取用户信息获取用户列表、获取用户详情
users:write创建、修改用户创建用户、更新用户
注意：令牌有效期为 2 小时（expires_in 秒）。过期后接口返回 401，请重新获取令牌。client_secret 只应保存在服务端，切勿写入前端代码或移动端安装包。

错误码

请求失败时返回非 2xx 状态码，响应体统一为以下结构：

错误响应结构 
{
  "error": {
    "code": "validation_failed",
    "message": "email 格式不正确",
    "field": "email",
    "request_id": "req_9a8b7c6d"
  }
}
HTTP 状态码code说明
400validation_failed请求参数缺失或格式错误
401unauthorized未携带令牌、令牌无效或已过期
403forbidden令牌缺少所需的 scope
404not_found资源不存在
409conflict资源冲突，如邮箱已被注册
429rate_limited请求过于频繁
500internal_error服务端错误，请携带 request_id 联系支持

用户对象

以下接口返回的用户数据均为此结构。

字段类型说明
idstring用户唯一 ID，以 usr_ 开头
namestring用户姓名，1–64 个字符
emailstring邮箱，全局唯一
phonestring | null手机号，E.164 格式，如 +8613800138000
rolestringadmin / member / guest

created_atstring创建时间
updated_atstring最后更新时间

获取用户列表

GET /users 需要 scope：users:read

分页返回用户列表，按 created_at 倒序排列。

查询参数

参数类型必填说明
pageinteger可选页码，从 1 开始，默认 1
page_sizeinteger可选每页条数，1–100，默认 20
statusstring可选按状态筛选：active / disabled
keywordstring可选按姓名或邮箱模糊搜索
请求示例 
curl "https://api.example.com/v1/users?page=1&page_size=2&status=active" \
  -H "Authorization: Bearer $ACCESS_TOKEN"

获取用户详情

GET /users/{id} 需要 scope：users:read

根据用户 ID 获取单个用户。

路径参数

参数类型必填说明
idstring必填用户 ID
请求示例 
curl https://api.example.com/v1/users/usr_01HZX3K9 \
  -H "Authorization: Bearer $ACCESS_TOKEN"
响应示例 · 200 OK 
{
  "id": "usr_01HZX3K9",
  "name": "张三",
  "email": "zhangsan@example.com",
  "phone": "+8613800138000",
  "role": "admin",
  "status": "active",
  "created_at": "2026-10-20T02:15:00Z",
  "updated_at": "2026-10-22T09:00:00Z"
}

用户不存在时返回 404 not_found。

创建用户

POST /users 需要 scope：users:write

创建一个新用户，成功后返回 201 Created，响应头 Location 为新用户的资源地址。

请求体

字段类型必填说明
namestring必填用户姓名，1–64 个字符
emailstring必填邮箱，不可与已有用户重复
passwordstring必填8–64 位，需同时包含字母与数字；不会出现在任何响应中
phonestring可选手机号，E.164 格式
rolestring可选默认 member
请求示例 
curl -X POST https://api.example.com/v1/users \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 5f1c2e9a-3b7d-4c11-9e0a-8d2f6b4a1c33" \
  -d '{
    "name": "王五",
    "email": "wangwu@example.com",
    "password": "Passw0rd2026",
    "role": "member"
  }'
响应示例 · 201 Created 
{
  "id": "usr_01HZX7QW",
  "name": "王五",
  "email": "wangwu@example.com",
  "phone": null,
  "role": "member",
  "status": "active",
  "created_at": "2026-10-25T08:30:00Z",
  "updated_at": "2026-10-25T08:30:00Z"
}
建议携带 Idempotency-Key 请求头（任意 UUID）。24 小时内使用相同 Key 重试将返回首次请求的结果，避免网络重试导致重复创建。邮箱已存在时返回 409 conflict。

更新用户

PATCH /users/{id} 需要 scope：users:write

部分更新用户信息，只需传入要修改的字段，未传字段保持不变。返回更新后的完整用户对象。

路径参数

参数类型必填说明
idstring必填用户 ID

请求体（至少包含一个字段）

字段类型说明
namestring用户姓名
emailstring邮箱，不可与其他用户重复
phonestring | null传 null 可清空手机号
rolestringadmin / member / guest
statusstring设为 disabled 可停用该用户，其令牌立即失效
请求示例 
curl -X PATCH https://api.example.com/v1/users/usr_01HZX7QW \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "+8613900139000",
    "role": "admin"
  }'
响应示例 · 200 OK 
{
  "id": "usr_01HZX7QW",
  "name": "王五",
  "email": "wangwu@example.com",
  "phone": "+8613900139000",
  "role": "admin",
  "status": "active",
  "created_at": "2026-10-25T08:30:00Z",
  "updated_at": "2026-10-25T09:12:47Z"
}
