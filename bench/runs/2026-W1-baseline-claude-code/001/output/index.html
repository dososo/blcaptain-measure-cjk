烘焙理念

少

每锅只烘 3 公斤。量小，才看得清每一颗豆子的颜色变化，也才来得及在对的那一秒出锅。

慢

生豆到店先静置、测含水率，再定曲线。一支新豆至少试烘五锅、杯测三轮，才上架。

真

不追深烘遮瑕，也不为酸而酸。产地给了什么风味，我们就尽量原样交到你手里。

好咖啡不在烘焙师的手艺里炫耀，
而在你喝第二口时，才慢慢说话。
