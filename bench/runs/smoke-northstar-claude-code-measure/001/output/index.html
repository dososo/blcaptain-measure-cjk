02

烘焙理念

先喝生豆的样品，再决定买不买

每年我们会杯测四十到六十支生豆样品，最后留下来的通常不到十支。挑豆的标准很简单：它本身好不好喝，以及我们能不能把它烘好。

烘到刚好，不追求越浅越好

浅烘能保留产地风味，但烘得不够熟，喝起来会有青草味和涩感。我们会为每一支豆子单独调整曲线，让花果香出来的同时，甜感也到位。

每一锅都有记录

入豆温度、回温点、一爆时间、出锅温度，每一锅都记在本子上，也会贴在豆袋背面。下次你喝到觉得特别好的那一包，我们能找到它是怎么烘出来的。

我们不做大批量，也不打算开分店。能看着每一锅出炉，是我们留在这个规模的原因。
