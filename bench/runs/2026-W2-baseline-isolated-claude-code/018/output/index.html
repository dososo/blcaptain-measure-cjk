智能门锁使用说明

这里介绍三项常用操作：录入指纹、更换电池和恢复出厂设置。不同型号的按键位置和语音提示可能略有差别，请以门锁实际播报和随附的纸质说明书为准。

  • 录入指纹
  • 更换电池
  • 恢复出厂设置

1录入指纹

首次使用时，第一个录入的用户会被设为管理员。之后要添加或删除用户，都需要先验证管理员身份。

  • 耗时约 1 分钟
  • 每只手指需按压 4–6 次
  • 最多可存 100 枚指纹（视型号而定）

操作步骤

  1. 唤醒门锁

    用手掌轻触室外面板的数字键区，键盘亮起即表示已唤醒。

  2. 进入管理菜单

    输入 * #，再验证管理员身份（管理员指纹或管理员密码 + #）。首次使用、尚未设置管理员时可直接进入。

  3. 选择“添加用户 → 添加指纹”

    按语音提示依次选择：1 用户设置 → 1 添加用户 → 1 指纹。门锁会播报分配到的用户编号，请记下来，日后删除时要用到。

  4. 按压指纹

    将手指平放在指纹识别区，听到“嘀”声后抬起，再次放下。每次稍微变换按压角度和位置，让手指中心和边缘都能被采集到。

  5. 完成录入

    听到“录入成功”即完成。按 * 可继续录入下一枚，或等待 10 秒自动退出菜单。

  6. 测试开锁

    退出菜单后用刚录入的手指试开一次，确认能正常识别。

录入小建议

  • 每人至少录入两只手指，一只受伤或脱皮时还能用另一只开门。
  • 手指保持干净、干燥，过湿或过干都会降低识别率。冬天手指干燥时，可以先哈口气再按。
  • 老人和小孩的指纹较浅，建议多录几次同一只手指，或改用密码、门卡开锁。

2更换电池

门锁播报“电量低，请更换电池”后，一般还能开锁约 100–200 次。请尽快更换，不要等到完全没电。

  • 耗时约 3 分钟
  • 需要 8 节 5 号（AA）碱性电池
  • 更换后用户数据不会丢失

操作步骤

  1. 找到电池仓

    电池仓在室内面板上，一般位于把手上方，盖板底部有一个小凹槽。

  2. 打开电池盖

    用指甲扣住凹槽向上推开盖板。部分型号的盖板有固定螺丝，需要先用十字螺丝刀拧下来。

  3. 取出旧电池

    一次性取出全部旧电池，不要新旧混用。

  4. 装入新电池

    按照电池仓内标注的 + / − 方向逐节装入，装好后门锁会发出提示音。

  5. 盖回盖板并测试

    盖好电池盖（有螺丝的拧紧），在门外用指纹或密码试开一次，并核对门锁时间是否正确。

电池类型是否推荐说明
碱性电池（Alkaline）推荐电压稳定，正常使用约 8–12 个月。
普通碳性电池不推荐容量小，低温下电压容易骤降。
镍氢充电电池不推荐单节电压只有 1.2V，可能导致电量误报或电机无力。

电池完全没电时怎么开门？

在室外面板底部找到 USB-C 应急供电口，用充电宝或手机数据线临时供电，再用指纹或密码开锁，进门后立即更换电池。也可以使用随锁附带的机械钥匙开门。请把机械钥匙存放在门外安全的地方（例如车里或办公室），不要锁在屋内。

3恢复出厂设置

适用于更换房主、忘记管理员密码或门锁工作异常等情况。恢复后门锁会回到首次使用的状态。

操作前请注意

  • 恢复出厂设置会清除所有指纹、密码、门卡和管理员信息，且无法撤销。
  • 操作期间请保持门处于打开状态，避免恢复后被锁在门外。
  • 如果门锁绑定了手机 App，请先在 App 中解绑，否则可能无法重新配网。

操作步骤

  1. 打开门，取下电池盖

    在室内一侧按“更换电池”中的方法打开电池仓盖。

  2. 找到复位键

    复位键是电池仓旁边一个标有 RESET 的小圆孔或小按钮。

  3. 长按复位键

    用卡针或回形针按住复位键约 5 秒，直到门锁播报“恢复出厂设置，请按 # 确认”。

  4. 确认恢复

    在室外键盘上按 # 确认，等待约 10 秒，听到“恢复出厂设置成功”即完成。若想放弃，按 * 取消。

  5. 重新设置

    此时任何指纹都能开门，请立即按“录入指纹”的步骤重新设置管理员。

?常见问题

遇到问题时，可以先在这里找找答案。

指纹总是识别失败怎么办？

先用干净的软布擦拭指纹识别区，再擦干手指重试。仍然频繁失败的话，建议删除该指纹后重新录入，录入时多变换几次按压角度。

连续输错几次会怎样？

连续验证失败 5 次后，门锁会锁定 3 分钟并发出警报，期间无法用指纹或密码开锁，可使用机械钥匙。

换完电池后门锁没反应？

请检查电池正负极是否装反、是否有电池接触不良。可以把每节电池稍微转动一下，让它和弹簧片接触良好。

忘记管理员密码怎么办？

如果还记得管理员指纹，可以用指纹进入菜单修改密码；如果管理员指纹和密码都无法使用，只能恢复出厂设置后重新录入。

本说明为通用操作指南，具体按键和功能以所购型号为准。
