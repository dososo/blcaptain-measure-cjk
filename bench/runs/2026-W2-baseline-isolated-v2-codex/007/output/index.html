每到月底，你是否也在重复这些步骤：打开文件、复制粘贴、整理数据、调整格式？其实，用几段 Python 代码，就能把这套流程自动化。这篇文章从一份销售报表出发，分享 5 个可以直接用起来的技巧。

开始之前

示例使用 Python 3.10+，需要 pandas 和 openpyxl。
准备环境：pip install pandas openpyxl

假设工作表「销售明细」包含：订单编号、日期、区域、产品、销售额。
以下片段按顺序运行，金额为数值或带千位分隔符的文本。

01

精准读取，只拿需要的数据

不必把整份工作簿搬进内存。用 sheet_name 指定工作表，配合 usecols 读取需要的列，让后续处理更清晰。

01_read.py
import pandas as pd

columns = ["订单编号", "日期", "区域", "产品", "销售额"]
df = pd.read_excel(
    "销售报表.xlsx",
    sheet_name="销售明细",
    usecols=columns,
    dtype={"订单编号": "string"},  # 保留文本编号的前导零
    engine="openpyxl",
)

print(df.head())

订单编号请在源文件中存成文本。如果单元格实际存储的是数字，dtype 无法恢复仅由 Excel 显示格式补上的前导零。

02

统一清洗，让数据先变可靠

空白字符、重复记录、混合类型，都是统计出错的常见原因。先规范文本和金额，再把不完整的数据单独保存，方便回查。

02_clean.py
def clean_sales(frame):
    data = frame.copy()
    for col in ["订单编号", "区域", "产品"]:
        data[col] = data[col].astype("string").str.strip()
        data[col] = data[col].replace("", pd.NA)

    amounts = data["销售额"].astype("string").str.replace(
        ",", "", regex=False
    )
    data["销售额"] = pd.to_numeric(amounts, errors="coerce")
    data["日期"] = pd.to_datetime(data["日期"], errors="coerce")
    data = data.drop_duplicates(subset=columns)

    invalid = data[columns].isna().any(axis=1)
    return data.loc[~invalid].copy(), data.loc[invalid].copy()

df, rejected = clean_sales(df)
rejected.to_excel("待核对数据.xlsx", index=False)

这里仅删除五列完全相同的记录。若业务允许内容相同的多条明细，请改用唯一的明细编号去重。日期示例假设源数据为日期单元格或日期文本。

03

批量合并，告别反复复制粘贴

把各区域的原始报表放进 reports/ 文件夹，一次读取、统一清洗，再用 pd.concat() 按行拼接。顺手记录来源文件，之后排查数据会轻松很多。

03_merge.py
from pathlib import Path

files = sorted(
    p for p in Path("reports").glob("*.xlsx")
    if not p.name.startswith("~$")  # 跳过 Excel 临时文件
)
if not files:
    raise FileNotFoundError("reports 文件夹中没有 .xlsx 报表")

frames, issues = [], []
for file in files:
    raw = pd.read_excel(
        file, sheet_name="销售明细", usecols=columns,
        dtype={"订单编号": "string"}, engine="openpyxl"
    )
    valid, invalid = clean_sales(raw)
    frames.append(valid.assign(来源文件=file.name))
    issues.append(invalid.assign(来源文件=file.name))

df = pd.concat(frames, ignore_index=True)
pd.concat(issues, ignore_index=True).to_excel(
    "批量待核对.xlsx", index=False
)

输入文件需使用相同的表名和列结构；输出文件请放在 reports 之外。本例不跨文件去重，合并前应确认各区域报表没有重叠数据。

04

一张透视表，看清业务重点

想知道每个区域、每类产品卖了多少？用 pivot_table() 把明细转换成汇总表，指定求和逻辑，并自动补齐没有销售记录的组合。

04_pivot.py
summary = df.pivot_table(
    index="区域",
    columns="产品",
    values="销售额",
    aggfunc="sum",
    fill_value=0,
    margins=True,
    margins_name="合计",
)

print(summary)
OUTPUT PREVIEW / 示例结果
销售额汇总示意，具体数值取决于输入数据

以上为示意数据。margins 会同时生成合计行和合计列；源数据中的区域、产品名称应避免使用保留名称「合计」。

05

导出后多一步，让报表更好读

pandas 负责写入数据，openpyxl 负责整理样式。把明细和汇总写进同一个文件，再设置表头、列宽、冻结窗格与金额格式，一份可交付的报表就完成了。

05_export.py
from openpyxl.styles import Font, PatternFill, Alignment
from openpyxl.utils import get_column_letter

with pd.ExcelWriter("销售分析.xlsx", engine="openpyxl") as writer:
    df.to_excel(writer, sheet_name="销售明细", index=False)
    summary.to_excel(writer, sheet_name="区域汇总")

    for ws in writer.book.worksheets:
        ws.freeze_panes = "B2"
        for cell in ws[1]:
            cell.font = Font(bold=True, color="FFFFFF")
            cell.fill = PatternFill("solid", fgColor="59654C")
            cell.alignment = Alignment(horizontal="center")

        for col_idx in range(1, ws.max_column + 1):
            letter = get_column_letter(col_idx)
            ws.column_dimensions[letter].width = 20

    detail = writer.sheets["销售明细"]
    detail.auto_filter.ref = detail.dimensions
    amount_col = df.columns.get_loc("销售额") + 1
    for row in detail.iter_rows(min_row=2):
        row[amount_col - 1].number_format = '#,##0.00'

    report = writer.sheets["区域汇总"]
    for row in report.iter_rows(min_row=2, min_col=2):
        for cell in row:
            cell.number_format = '#,##0.00'

print("完成：销售分析.xlsx")

ExcelWriter 会在退出 with 代码块时保存文件。同名输出会被覆盖；需要保留历史版本时，可在文件名中加入报表月份。
