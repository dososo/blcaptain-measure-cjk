用 Python 处理 Excel 报表的 5 个技巧

2026 年 10 月 26 日 阅读约 8 分钟 pandas 2.2 · openpyxl 3.1

每到月底，总有人要把十几个部门交上来的 Excel 拼成一张汇总表，再调格式、标颜色、发邮件。这些重复劳动大部分都可以交给 Python。下面五个技巧来自真实的报表脚本，每个都附了能直接运行的代码。

示例默认你已经装好了 pandas 和 openpyxl。文中的文件名和列名都是虚构的，换成自己的即可。

本文目录

01一次读入所有工作表并合并

很多报表按月份或部门分成多个工作表，结构完全一样。逐个调用 read_excel 既啰嗦又容易漏表。把 sheet_name 设成 None，pandas 会返回一个字典：键是工作表名，值是对应的 DataFrame。

merge_sheets.py
import pandas as pd

# sheet_name=None：读取全部工作表，返回 {表名: DataFrame}
sheets = pd.read_excel("2026年销售明细.xlsx", sheet_name=None)

# 合并时把来源表名记成一列，方便后面按月份筛选
df = pd.concat(
    [d.assign(月份=name) for name, d in sheets.items()],
    ignore_index=True,
)

print(df.shape)        # (行数, 列数)
print(df["月份"].unique())

如果要合并的是一个文件夹里的多个文件，思路相同，只是外面再套一层 glob：

merge_files.py
from pathlib import Path
import pandas as pd

frames = []
for path in sorted(Path("部门报表").glob("*.xlsx")):
    if path.name.startswith("~$"):   # 跳过 Excel 打开时生成的临时文件
        continue
    d = pd.read_excel(path)
    d["来源文件"] = path.stem
    frames.append(d)

df = pd.concat(frames, ignore_index=True)

提示各部门的列名常常不统一，比如“金额”和“金额（元）”。合并前先用 d.columns = d.columns.str.strip() 去掉首尾空格，再用一个映射字典统一列名，能少踩很多坑。

02写回已有文件，不破坏原来的格式

直接 df.to_excel("报表.xlsx") 会生成一个全新的文件，原来的表头样式、公司 Logo、其他工作表统统丢失。正确的做法是用追加模式打开 ExcelWriter，只覆盖需要更新的区域。

write_back.py
import pandas as pd

summary = df.groupby("区域", as_index=False)["销售额"].sum()

with pd.ExcelWriter(
    "月度报表模板.xlsx",
    engine="openpyxl",
    mode="a",                     # 追加到已有文件
    if_sheet_exists="overlay",     # 只写数据，保留原有样式
) as writer:
    summary.to_excel(
        writer,
        sheet_name="汇总",
        startrow=3,                 # 从第 4 行开始写，留出模板的标题区
        index=False,
        header=False,
    )

if_sheet_exists 有四个取值，含义差别很大：

取值行为
"error"工作表已存在就报错（默认）
"new"新建一个带数字后缀的工作表，比如“汇总1”
"replace"删掉原表再新建，格式会丢
"overlay"在原表上直接写入单元格，格式保留

注意写入前要关掉 Excel 里打开的同名文件，否则在 Windows 上会遇到 PermissionError。另外，openpyxl 不会保留图表和数据透视表之外的一些高级对象，重要模板记得先备份。

03用 pivot_table 生成汇总报表

在 Excel 里拖数据透视表很直观，但每个月都要重新拖一遍。pivot_table 能用一行代码得到同样的结果，而且可以加上合计行。

pivot.py
report = pd.pivot_table(
    df,
    index="区域",              # 行
    columns="月份",            # 列
    values="销售额",           # 值
    aggfunc="sum",
    fill_value=0,              # 没有数据的格子填 0，而不是 NaN
    margins=True,              # 加上合计行和合计列
    margins_name="合计",
)

# 让月份按自然顺序排列，而不是按字符串排序
order = [f"{m}月" for m in range(1, 13)]
report = report.reindex(
    columns=[c for c in order if c in report.columns] + ["合计"]
)

report.to_excel("区域月度汇总.xlsx")

需要同时统计多个指标时，给 aggfunc 传字典即可，例如 {"销售额": "sum", "订单号": "nunique"}，一张表里就能看到金额和订单数。

04自动调整列宽并加条件格式

pandas 导出的表格列宽都是默认值，长一点的文字会被截断，数字也没有千分位。用 openpyxl 再处理一遍，报表看起来就像手工调过的。

beautify.py
from openpyxl import load_workbook
from openpyxl.formatting.rule import CellIsRule, ColorScaleRule
from openpyxl.styles import Font, PatternFill
from openpyxl.utils import get_column_letter

wb = load_workbook("区域月度汇总.xlsx")
ws = wb.active

def display_width(value):
    """中文字符按 2 个宽度计算，英文和数字按 1 个。"""
    text = str(value) if value is not None else ""
    return sum(2 if ord(ch) > 127 else 1 for ch in text)

# 1. 按每列最长的内容设置列宽
for col in ws.iter_cols():
    width = max(display_width(c.value) for c in col)
    ws.column_dimensions[get_column_letter(col[0].column)].width = width + 2

# 2. 表头加粗、冻结首行
for cell in ws[1]:
    cell.font = Font(bold=True)
ws.freeze_panes = "B2"

# 3. 数字加千分位
data_range = f"B2:{get_column_letter(ws.max_column)}{ws.max_row}"
for row in ws[data_range]:
    for cell in row:
        cell.number_format = "#,##0"

# 4. 条件格式：低于 10 万标红，整体加三色色阶
ws.conditional_formatting.add(
    data_range,
    CellIsRule(operator="lessThan", formula=["100000"],
               fill=PatternFill("solid", fgColor="F8D7D3")),
)
ws.conditional_formatting.add(
    data_range,
    ColorScaleRule(start_type="min", start_color="FFFFFF",
                   end_type="max", end_color="63BE7B"),
)

wb.save("区域月度汇总.xlsx")

这里用的是 Excel 原生的条件格式，而不是把颜色直接写进单元格。好处是同事在 Excel 里改了数字，颜色会跟着变。

05读取大文件时省内存

几十万行的导出文件，用默认参数读进来可能要占好几 GB 内存，还要等上一两分钟。三个参数能明显改善：只读需要的列，提前指定类型，以及把重复值多的文本列设成 category。

read_large.py
df = pd.read_excel(
    "全年订单导出.xlsx",
    usecols=["订单日期", "区域", "产品线", "销售额"],   # 只读需要的列
    dtype={
        "区域": "category",       # 重复值多的文本列，内存可降到十分之一
        "产品线": "category",
        "销售额": "float32",
    },
    parse_dates=["订单日期"],
)

print(df.memory_usage(deep=True).sum() / 1024**2, "MB")

如果文件大到连读进来都困难，可以用 openpyxl 的只读模式逐行处理，边读边累加，内存占用几乎是常数：

stream_rows.py
from collections import defaultdict
from openpyxl import load_workbook

wb = load_workbook("全年订单导出.xlsx", read_only=True, data_only=True)
ws = wb.active

totals = defaultdict(float)
rows = ws.iter_rows(min_row=2, values_only=True)   # 跳过表头
for date, region, product, amount in rows:
    totals[region] += amount or 0

wb.close()   # 只读模式会占用文件句柄，用完要关闭
print(dict(totals))

提示data_only=True 读取的是公式的计算结果，而不是公式本身。但这个结果是 Excel 上次保存时缓存的；如果文件是由程序生成、从没在 Excel 里打开过，读到的会是 None。

小结

把这五个技巧串起来，就是一条完整的报表流水线：合并原始数据，透视汇总，写回模板，最后统一美化。整个脚本通常不超过一百行，跑一次只要几秒钟。

建议先从你每个月最耗时的那一步开始改，跑通之后再逐步把其他环节接进来。等整条流程稳定了，再配合定时任务，月底那一天就能轻松很多。
