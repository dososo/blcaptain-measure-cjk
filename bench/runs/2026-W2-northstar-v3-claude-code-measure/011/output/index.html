常见问题

会员到期后，已经下载的素材还能用吗？

可以。会员期内下载的素材，授权永久有效，到期后已完成的作品也不用下架。

个人商用和企业商用有什么区别？

个人商用适合自由职业者给客户做项目；企业商用以公司名义授权，可以用在广告投放、产品包装和大批量印刷品上。

可以中途从专业版升级到团队版吗？

可以。升级时按剩余天数折算差价，原来的下载记录和收藏夹会自动迁移到团队空间。

支持哪些付款方式？

支持微信支付、支付宝和对公转账。团队版按年付时可以先开票后付款。

开通后不满意可以退款吗？

开通 7 天内、下载量不超过 20 个，可以申请全额退款。
