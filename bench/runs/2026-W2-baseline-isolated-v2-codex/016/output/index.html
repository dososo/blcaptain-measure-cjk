文档/开始使用/快速上手
A small tool. A better workflow.

从这里，开始构建。

认识 Orbit，一个轻量、直观的开源命令行工具。
从初始化到构建，把重复的工作交给终端，把时间留给创造。

约 5 分钟macOS · Linux · Windows适合初次使用
开始之前请准备 Node.js 20 或更高版本，以及 npm。
在终端运行 node -v 和 npm -v，确认环境已就绪。
01

安装 Orbit

打开终端，使用 npm 全局安装。只需一条命令，即刻启程。

Terminal
$npm install -g @orbit-example/cli
安装完成后，运行 orbit --version，看到版本号即表示安装成功。
02

配置你的工作空间

在项目根目录创建 orbit.config.json，让 Orbit 适应你的工作方式。

orbit.config.json
{
  "name": "my-project",
  "port": 3000,
  "outDir": "dist"
}

name 是项目名称，port 是本地端口，outDir 是构建输出目录。所有配置均可按需修改。

03

三个命令，覆盖日常

创建、开发、构建。你的下一个项目，从这里开始。

初始化项目

在当前空目录生成项目结构与默认配置，准备开始。

orbit init

启动本地开发

在项目目录启动开发服务，默认访问 localhost:3000。

orbit dev

构建生产版本

在项目目录生成优化后的静态文件，输出到 dist 目录。

orbit build

首次使用先运行 orbit init，再调整配置。开发服务可通过 Ctrl + C 停止。

准备好了，去创造吧。

忘记参数？运行 orbit --help，随时查看命令帮助。
