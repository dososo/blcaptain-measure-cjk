Roasting Philosophy

我们的烘焙理念

烘焙不是给豆子“加味道”，而是把它已经拥有的东西找出来。

01

源头可追溯

优先与小农和处理站直接合作，清楚每一袋生豆来自哪片山坡、经过怎样的处理。

02

小批量，勤烘焙

每次只烘 3–5 公斤，每周两次出炉。不囤货，让你拿到手的永远是新鲜的豆子。

03

为每支豆子定制曲线

不同产地、密度与处理法，需要不同的火力与节奏。每支新豆都会经过多轮试烘与杯测才上架。

04

好喝，但不设门槛

精品咖啡不必高高在上。来店里聊聊你喜欢的味道，我们帮你挑一支合适的豆子。
