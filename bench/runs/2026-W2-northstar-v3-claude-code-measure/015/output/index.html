常见问题

免费额度用完后会自动扣费吗？

只有在控制台开启了按量付费，超出部分才会计费；没有开启时，接口会返回 429，直到下月额度重置。

没用完的免费额度能留到下个月吗？

不能。免费额度每月 1 日重置，不累计、不折现。

怎么查看用量和账单？

控制台的“用量”页面按小时更新各接口的调用次数，账单在每月 3 日前生成，可以下载明细。

可以设置消费上限吗？

可以。在控制台为每个接口设置月度预算，达到上限后自动停止计费调用，并发送邮件提醒。
