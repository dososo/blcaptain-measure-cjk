  1. 贴进草稿

    零散的要点、聊天记录、写了一半的段落都可以，不用先整理格式。

    选择“周报”或“邮件”，写一句收件人是谁、希望对方做什么。语气可以选正式、简洁或亲和。

    每一处改动都会标出来并说明原因，你可以逐条接受或撤回，最后一键复制到飞书、钉钉或邮箱。

常见问题

落笔会不会编造我没做过的工作？
不会。落笔只重新组织你提供的内容；发现缺少数字或结论时，会用高亮提示你自己补上，而不是替你填一个数。
我的周报和邮件内容安全吗？
草稿只用于本次改写，默认不保存，也不会用于训练模型。团队版支持私有化部署。
能学会我们公司的周报格式吗？
可以。上传一两份过去的周报作为模板，之后的改写都会沿用相同的结构和用词习惯。
支持英文邮件吗？
支持。你可以用中文写要点，让落笔直接输出英文邮件，也可以把收到的英文邮件翻译后再起草回复。
