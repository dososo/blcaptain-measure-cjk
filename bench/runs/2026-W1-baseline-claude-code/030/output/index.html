租房笔记 · 看房篇

租房前
一定要检查的
6 个地方

看房十分钟，住进去少踩一年坑。

  1. 壹

    水压与排水

    冷热水全开，冲一次马桶，看地漏下水快不快、有没有返味。

  2. 贰

    电路与插座

    带个充电器逐个试插座；问清空调、热水器是否走专线。

  3. 叁

    门锁与门窗

    确认能换锁芯；窗户关严后不漏风,纱窗完好无破洞。

  4. 肆

    墙角与天花

    重点看卫生间、窗边和柜子背后，有霉斑水渍要警惕。

  5. 伍

    燃气与热水器

    看软管有没有老化、热水器用了几年，有无燃气报警器。

  6. 陆

    水电燃气表底

    入住当天拍下三表读数，和房东一起确认，写进合同。

签合同前，逐项拍照留证家具家电的现有损坏,也一并记下来。
