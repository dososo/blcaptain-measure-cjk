常见问题

忘记密码怎么办？

在 SSO 登录页点击「忘记密码」，通过手机验证码自助重置；如手机号未绑定，请联系 IT 服务台。

试用期多长？什么时候转正？

以劳动合同约定为准。试用期结束前，上级会与你进行转正评估面谈，HR 会提前通知流程。

第一周可以请假吗？

可以，在 HR 系统提交请假申请并提前告知上级。新员工的年假额度按入职时间折算。

怎么报销入职当天的费用？

在 OA 审批中提交报销单并上传发票，具体标准参见知识库中的《费用报销制度》。

如有内容需要更新，请联系 HR 部门。祝你在这里工作愉快！
