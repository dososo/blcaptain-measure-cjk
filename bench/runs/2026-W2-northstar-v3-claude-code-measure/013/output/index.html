常见问题

没找到答案？发邮件到 help@qingxia.example，我们会在一个工作日内回复。

容量用完了会怎样？文件会被删除吗？

不会删除。容量用满后，已有文件仍可正常查看、下载和分享，只是不能再上传新文件，手机相册的自动备份也会暂停。

清理出空间或升级到更高一档后，备份会自动继续。

中途升级或降级，费用怎么算？

升级立即生效，当前周期剩余的天数按新旧两档的差价折算，只需补齐差额。

降级在当前周期结束后生效。降级前请确认已用空间不超过新档位的容量，否则超出部分只能查看和下载，不能继续上传。

可以退款吗？

首次购买付费档位后 14 天内，可以无条件全额退款，在“账户设置 → 订单”里提交即可。超过 14 天的年付订单，按未使用的整月数退还。

家庭版的成员能看到彼此的文件吗？

不能。每位成员都有独立的私人空间，只有放进共享相册或共享文件夹的内容，其他成员才看得到。管理员可以看到每个人用了多少容量，但看不到文件内容。

我的文件存放在哪里？安全吗？

文件存放在国内两个相距 1000 公里以上的数据中心，每份数据至少保存 3 个副本。传输过程使用 TLS 加密，存储时使用 AES-256 加密。

专业版还可以开启“私密保险箱”，用只有你知道的密码再加密一层，我们的工作人员也无法解密。

上传和下载会限速吗？

所有档位都不限速，实际速度取决于你的网络带宽。免费版每天的分享链接下载总流量为 10GB，付费档位不设上限。

停止续费后，数据会保留多久？

付费到期后自动转为免费版。如果已用空间超过 5GB，文件会继续保留 180 天，期间可以随时下载或重新续费；到期前我们会发三次邮件提醒。

支持哪些付款方式？能开发票吗？

支持微信支付、支付宝和银联卡，年付订单还可以对公转账。付款后可以在订单页面申请电子发票，增值税普通发票和专用发票都能开。
