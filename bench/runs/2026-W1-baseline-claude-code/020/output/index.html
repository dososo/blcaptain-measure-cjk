账号安全须知

  1. 拿到初始密码后第一时间修改，不要和其他网站用同一个密码。
  2. 密码、验证码不要发到群聊、邮件或截图里，任何人索要都不要给，包括自称 IT 的人。
  3. 离开工位时锁屏（macOS：Control + Command + Q；Windows：Win + L）。
  4. 收到可疑邮件或链接，先别点，转发给 IT 确认。
