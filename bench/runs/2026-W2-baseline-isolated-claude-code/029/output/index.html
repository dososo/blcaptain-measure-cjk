睡前书单

关灯前，
读这 5 本书

不烧脑 · 不揪心 · 读几页就安静下来

  1. 01
    《小王子》圣埃克苏佩里

    每晚一颗小星球，像童年听过的睡前故事。

    治愈
  2. 02
    《枕草子》清少纳言

    一段一则的随笔，从哪页翻开都刚刚好。

    碎片
  3. 03
    《浮生六记》沈复

    寻常日子里的闲情与温柔，读完心是软的。

    温柔
  4. 04
    《瓦尔登湖》梭罗

    湖光、林声、四季，慢到让人想打哈欠。

    安静
  5. 05
    《夜晚的潜水艇》陈春成

    短篇里的奇妙梦境，适合带着想象入睡。

    入梦
