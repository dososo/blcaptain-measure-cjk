API REFERENCE

用户 Users

在你的应用中轻松管理用户。通过简洁、一致的 REST 接口，
获取用户信息、创建新用户，以及更新和删除已有用户。

API v1HTTPSJSON 格式UTF-8 编码
BASE URLhttps://api.example.com/v1

身份鉴权

#

所有接口均使用 Bearer Token 进行身份验证。请在每次请求的
Authorization 请求头中携带有效的 API Token。

请求头Bearer Token
Authorization: Bearer YOUR_API_TOKEN
请妥善保管你的 Token
仅在服务端保存和使用，避免暴露在前端代码或公开仓库中。Token 缺失、无效或过期时，接口将返回 401 Unauthorized。

用户接口

4 endpoints#

围绕用户资源的四个基础操作。点击接口查看完整的请求和响应说明。

METHOD / ENDPOINT所有接口均需鉴权
GET/users/{id}获取用户信息

根据用户的唯一 ID 获取其详细信息。

路径参数 PATH PARAMETERS

参数类型说明
id 必填string用户唯一标识，例如 usr_123

请求示例

curl --request GET 'https://api.example.com/v1/users/usr_123' \
  --header 'Authorization: Bearer YOUR_API_TOKEN'

响应示例

200 OK
{
  "data": {
    "id": "usr_123",
    "name": "Alex Chen",
    "email": "alex@example.com",
    "created_at": "2026-01-15T08:30:00Z"
  }
}

用户不存在时返回 404 Not Found。

POST/users创建新用户

创建一个新用户。请求体使用 JSON 格式，并设置 Content-Type: application/json。

请求体 REQUEST BODY

参数类型说明
name 必填string用户姓名，1–80 个字符
email 必填string有效且唯一的邮箱地址，最多 254 个字符

请求示例

curl --request POST 'https://api.example.com/v1/users' \
  --header 'Authorization: Bearer YOUR_API_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{"name":"Alex Chen","email":"alex@example.com"}'

响应示例

201 Created
{
  "data": {
    "id": "usr_123",
    "name": "Alex Chen",
    "email": "alex@example.com",
    "created_at": "2026-01-15T08:30:00Z"
  }
}

邮箱已注册时返回 409 Conflict；参数不合法时返回 400 Bad Request。

PATCH/users/{id}更新用户信息

部分更新用户信息。仅修改提交的字段，未提交的字段保持原值。至少提供一个字段，不接受 null。

路径参数 PATH PARAMETERS

参数类型说明
id 必填string待更新的用户唯一标识

请求体 REQUEST BODY

参数类型说明
namestring可选，用户姓名，1–80 个字符
emailstring可选，有效且唯一的邮箱，最多 254 个字符

请求示例

curl --request PATCH 'https://api.example.com/v1/users/usr_123' \
  --header 'Authorization: Bearer YOUR_API_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{"name":"Alex Wang"}'

响应示例

200 OK
{
  "data": {
    "id": "usr_123",
    "name": "Alex Wang",
    "email": "alex@example.com",
    "created_at": "2026-01-15T08:30:00Z"
  }
}

参数不合法返回 400，用户不存在返回 404，邮箱重复返回 409。

DELETE/users/{id}删除用户

永久删除指定用户，此操作无法撤销。请求不需要携带请求体。

路径参数 PATH PARAMETERS

参数类型说明
id 必填string待删除的用户唯一标识

请求示例

curl --request DELETE 'https://api.example.com/v1/users/usr_123' \
  --header 'Authorization: Bearer YOUR_API_TOKEN'

成功响应

204 No Content
HTTP/1.1 204 No Content

成功时不返回响应体。用户不存在或已删除时返回 404 Not Found。

未找到匹配的接口，请尝试搜索方法名或“用户”。

状态码与错误

#

使用标准 HTTP 状态码表示请求结果。错误响应包含稳定的错误标识和便于排查的说明。

400 Bad Request请求参数缺失或格式不正确
401 UnauthorizedToken 缺失、无效或已过期
403 Forbidden当前 Token 无权操作该资源
404 Not Found指定用户不存在
409 Conflict邮箱地址已被其他用户使用
500 Internal Server Error服务端异常，请稍后重试
{
  "error": {
    "code": "user_not_found",
    "message": "未找到指定用户。"
  }
}
