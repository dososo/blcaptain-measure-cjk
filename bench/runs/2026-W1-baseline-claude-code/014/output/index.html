常见问题

买了课时包能退吗？

购买 7 天内且未上课可全额退款；已上课的按单节原价扣除已用课时后退还余款。

一对一和小班课能互换吗？

可以。课时包未使用部分可按剩余金额折算，转换为另一种课程，差价多退少补。

课时包过期了怎么办？

到期前可申请延期一次，最长 30 天，不额外收费。

需要准备什么设备？

电脑、平板或手机都可以，建议佩戴耳机，保证网络稳定即可。
