常见问题

没找到答案？欢迎随时联系我们的客服团队

可以随时升级或降级方案吗？

可以。升级立即生效，差价按剩余天数折算；降级将在当前计费周期结束后生效。降级前请确保已用空间不超过新方案的容量。

超出容量后我的文件会怎样？

文件不会被删除。超出容量后将暂停新文件上传与同步，已有文件仍可正常查看和下载，清理空间或升级方案后即可恢复。

按年付和按月付有什么区别？

功能完全相同。按年付一次性支付 12 个月费用，相比按月付约节省 20%；按月付更灵活，可随时取消。

支持哪些付款方式？可以开发票吗？

支持支付宝、微信支付、银联卡及主流信用卡。付款完成后可在「账户 → 账单」中申请增值税普通发票或专用发票。

我的数据安全吗？

所有文件在上传前于本地加密，传输全程使用 TLS，存储时采用 AES-256 加密，并在多个数据中心冗余备份，数据持久性达 99.999999999%。我们无法查看你的文件内容。

可以退款吗？

首次购买付费方案后 14 天内，如不满意可申请全额退款，无需说明理由。

取消订阅后数据会保留多久？

取消后账户自动转为免费版。超出免费容量的文件会保留 90 天，期间可随时下载或重新订阅；90 天后才会被清理，我们会提前邮件提醒。
