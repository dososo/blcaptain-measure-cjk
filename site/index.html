让 AI 写的中文页面，
排得有分寸。

给 Claude Code、Codex 这类编码 Agent 用的中文排版 skill，加一个离线校验器 measure-cjk：查字号、字距、行长、行高、标点和字体授权，并用浏览器实测。

装上之后，差别有多大

同一个 Agent、同一个模型，30 条中文页面提示词，装和不装 measure 各生成一次，用 measure 的完整档检查。

规则示意

以下是示意，不是实验结果：同一段文字，“关”只差一条规则，“开”是按 measure 改好的版本。两版都用 measure-cjk lint --render 检查过：“关”只报这一条规则，“开”零 error。“关”的程度按实验里真实页面的情况设，不故意做得更差。

没有做示意的规则：T01（声明中文 lang）和 T13（字体栈里要有中文字体）的效果取决于浏览器和系统字体，一张图说明不了；T04（行首禁则）在 Chrome 里开不开，常用中文标点都不会落到行首，看不出差别。

T02中英文、中文与数字之间要有间距

汉字和字母、数字挤在一起，读的时候要自己找边界。measure.css 打开 text-autospace，浏览器自动留出约四分之一个字的空隙，文案里不用手打空格。

T03中文语境用全角标点

半角逗号、句号、问号又小又靠下，夹在汉字中间像没打完。中文句子用全角标点，字距才均匀。

T05正文行长 28–40 字

一行太长，眼睛从行尾回到下一行行首时容易串行。中文正文每行 28–40 个字最舒服，宽屏上要给正文限宽。

T06正文行高不低于 1.5

汉字是方块字，字面撑满整个字身，行与行之间比西文更需要留白。行高 1.35 时上下两行已经显得挤，正文建议 1.6–1.9。

T07中文字距不能为负

西文大标题常用负字距收紧，搬到中文上，笔画会碰在一起。中文标题保持默认字距，靠字重和留白拉开层次。

T08中文不用斜体

中文字体没有真正的斜体，浏览器只能把字形硬生生歪过去。强调中文，用加粗、颜色或着重号。

T11最小字号：正文 ≥ 14px，任何中文 ≥ 12px

西文 10px 还能辨认，汉字笔画多，10px 时笔画会糊成一团。价格说明、标签这类小字，中文也不要小于 12px。

真实页面：同一条提示词，装之前和装之后

每组第一张是不装 measure 时 Agent 生成的页面，红框是完整档查到的问题，标签是规则编号和在这张截图里当场量到的值；第二张是装了 measure 后，同一条提示词生成的页面。截图窗口都是 1280px 宽：第一张截红框所在的位置（多数就在首屏），第二张截首屏。

  • 计数不含 T02、T04（本项目自定的规则），也不含 T06：它对单行元素的判定有误报，正在修，红框里也没有标它。
  • 图注里的数字是整页的问题数；红框只画在截图范围内、而且 lint 给出了位置的问题（同一条规则 lint 最多列出 20 处的位置），所以框数会比图注里的数字少。
  • 怎么挑的：每个 Agent 各挑两组，偏向问题多、看得出差别的页面。按不装 measure 时的 error 数，这几组在各自 30 页里分别是：文章页（游记）（Codex）排第 4，价格页（Codex）排第 4，落地页（Claude Code）排第 7，文章页（随笔）（Claude Code）排第 14。Claude Code 不装 measure 时，排除 T02、T04 后本来就有一半页面零 error。
  • 装了 measure 之后仍报 error 的页面：Codex 0 页；Claude Code 3 页（012：1 → 4 处，T06；019：0 → 1 处，T06；028：20 → 3 处，T06）。

6 个主题

每个主题一个文件（不超过 8 KB）：设计变量、字号阶梯（字号越大字重越轻）、字体栈、该做和不该做。6 个示例页用同一段文字，CSS 原样取自主题文件，都用 measure-cjk lint --render 检查过。

怎么用

校验器单独发布在 npm 上，skill 按你用的 Agent 安装：

  • 校验器：npm install -g measure-cjk
  • Claude Code：/plugin marketplace add dososo/blcaptain-measure-cjk，再 /plugin install measure@blcaptain-measure-cjk
  • Codex：codex plugin marketplace add dososo/blcaptain-measure-cjk，再 codex plugin add measure@blcaptain-measure-cjk
  • 其他 Agent：npx skills add dososo/blcaptain-measure-cjk

源码、规则文档和实验数据在 GitHub。

截图里的中文统一用思源黑体、思源宋体，emoji 和符号用 Noto Color Emoji、Noto Sans Symbols 2 渲染（都是 OFL-1.1）；页面原本点名的英文字体照常显示。每张截图都逐个元素核对过实际用到的字体，没有系统中文字体，也没有系统 emoji 和符号字体。
