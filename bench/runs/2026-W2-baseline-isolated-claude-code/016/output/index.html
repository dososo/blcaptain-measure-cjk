shelf 快速上手

shelf 是一个开源命令行工具，用来收藏、检索和同步你常用的 shell 片段。照着本页操作，大约五分钟可以装好并跑通第一个命令。

1. 安装

选择适合你系统的方式。所有方式安装的都是同一个单文件可执行程序，不依赖额外运行时。

macOS / Linux
brew install shelf
shell
curl -fsSL https://example.org/shelf/install.sh | sh
需要 Rust 1.75+
cargo install shelf-cli
PowerShell
scoop install shelf

安装完成后，确认版本号：

shell
shelf --version
输出
shelf 1.4.0

提示 command not found？把安装目录（默认 ~/.local/bin）加入 PATH，然后重新打开终端。

2. 配置

第一次使用前运行初始化命令，它会在交互式问答后生成配置文件：

shell
shelf init

配置文件位于 ~/.config/shelf/config.toml（Windows 为 %APPDATA%\shelf\config.toml），也可以直接手动编辑：

~/.config/shelf/config.toml
# 片段存放目录
store = "~/.local/share/shelf"

# 用于编辑片段的编辑器，留空则读取 $EDITOR
editor = "vim"

# find 命令默认返回的结果数
limit = 20

[sync]
# 同步用的 Git 仓库地址，不需要同步可删掉整个 [sync] 段
remote = "git@github.com:you/shelf-snippets.git"
branch = "main"
配置项默认值说明
store~/.local/share/shelf片段文件的本地存放目录
editor$EDITOR执行 shelf add -e 时打开的编辑器
limit20搜索结果条数上限
sync.remote无用于多设备同步的 Git 远程仓库
sync.branchmain同步使用的分支

每个配置项都能用环境变量临时覆盖，格式为 SHELF_ 加大写键名，例如 SHELF_LIMIT=5 shelf find git。

3. 常用命令

下面三个命令覆盖了日常 90% 的用法：存进去、找出来、多设备同步。

shelf add — 收藏一个片段

把一条命令连同描述和标签存起来。不带参数时会把上一条 shell 历史命令作为内容。

shell
shelf add "git log --oneline --graph -20" -d "最近提交图" -t git
参数说明
-d, --desc片段描述，搜索时会匹配这段文字
-t, --tag标签，可重复使用多次
-e, --edit在编辑器里写多行片段

shelf find — 搜索并使用片段

按关键词模糊搜索内容、描述和标签，在交互列表中选中后按回车即可把命令放到剪贴板。

shell
shelf find git --tag git
输出
> git log --oneline --graph -20    最近提交图      #git
  git stash push -m "wip"          临时保存改动    #git
  git rebase -i HEAD~3             整理最近三次提交 #git
3 条结果 · ↑↓ 选择 · Enter 复制 · Ctrl-R 直接运行
参数说明
--tag只在指定标签内搜索
--run选中后直接执行，而不是复制
--json以 JSON 输出结果，便于脚本处理

shelf sync — 多设备同步

把本地片段与配置中的 sync.remote 仓库双向合并。冲突时会保留两份并提示你处理。

shell
shelf sync
输出
↓ 拉取 2 个新片段
↑ 推送 1 个本地改动
✓ 已同步，共 48 个片段
参数说明
--pull只拉取，不推送
--dry-run只显示将发生的变化，不实际写入

4. 下一步

  1. 运行 shelf <命令> --help 查看任意命令的完整参数。
  2. 执行 shelf completions zsh > ~/.zfunc/_shelf 开启 Tab 补全（也支持 bash、fish）。
  3. 遇到问题或想贡献代码，欢迎到项目仓库提交 Issue 或 Pull Request。
