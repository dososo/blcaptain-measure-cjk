5 分钟上手 snip

snip 是一个开源的命令行代码片段管理器：在终端里保存、搜索并在多台设备间同步常用的命令与代码片段。

MIT 许可证 macOS / Linux / Windows 单个二进制，无运行时依赖

1安装

选择适合你系统的安装方式。所有方式安装的都是同一个二进制文件 snip。

适用于 macOS 和 Linux：

shell
$ brew install snip-cli/tap/snip

脚本会自动识别系统与架构，并把 snip 安装到 ~/.local/bin：

shell
$ curl -fsSL https://snip.dev/install.sh | sh

Windows（PowerShell）：

powershell
PS> irm https://snip.dev/install.ps1 | iex

如果你已经装好 Rust 工具链（1.75 及以上）：

shell
$ cargo install snip-cli
shell
$ git clone https://github.com/snip-cli/snip.git
$ cd snip
$ cargo build --release
$ cp target/release/snip ~/.local/bin/

验证安装

shell
$ snip --version
snip 2.4.0
提示：找不到命令？ 确认安装目录已加入 PATH，例如在 ~/.zshrc 中加入 export PATH="$HOME/.local/bin:$PATH"，然后重新打开终端。

2配置

首次使用时运行初始化命令，snip 会生成默认配置文件并创建本地片段库：

shell
$ snip init
✔ 已创建配置文件 ~/.config/snip/config.toml
✔ 已创建片段库   ~/.local/share/snip/library.db

配置文件使用 TOML 格式，常用项如下：

~/.config/snip/config.toml
# 编辑片段时使用的编辑器，留空则读取 $EDITOR
editor = "vim"

# 未指定语言时的默认值
default_lang = "bash"

[search]
# 模糊匹配；设为 false 则使用精确匹配
fuzzy = true
max_results = 20

[sync]
# 用于同步的 Git 仓库地址（可选）
remote = "git@github.com:yourname/snippets.git"
auto = false
配置项默认值说明
editor$EDITOR新建或编辑片段时打开的编辑器
default_lang"text"片段的默认语言标签，影响高亮显示
search.fuzzytrue是否启用模糊搜索
search.max_results20单次搜索最多返回的结果数
sync.remote无同步用的 Git 远程仓库；不设置则只保存在本地
sync.autofalse每次添加或修改片段后自动同步

也可以直接在命令行修改单个配置项，而不必手动编辑文件：

shell
$ snip config set editor code
$ snip config get editor
code
环境变量优先 每个配置项都可以用 SNIP_ 前缀的环境变量覆盖，例如 SNIP_SEARCH_FUZZY=false。配置文件位置可通过 SNIP_CONFIG 指定。

3三个常用命令

掌握下面三个命令，就能覆盖日常 90% 的使用场景。任何命令都可以加 --help 查看完整参数。

snip add

保存一个新片段。可以从参数、标准输入或编辑器中读取内容。

shell
# 直接保存一条命令，并打上标签
$ snip add "docker system prune -af" --name docker-clean --tag docker

# 从管道读取文件内容
$ cat deploy.sh | snip add --name deploy --lang bash

# 不带内容时会打开编辑器
$ snip add --name nginx-conf
参数说明
-n, --name片段名称，需唯一；省略时自动生成
-t, --tag标签，可重复使用以添加多个
-l, --lang语言，用于语法高亮

snip find

按关键词、标签或语言搜索片段，并可直接复制或执行。

shell
$ snip find docker
  1  docker-clean   [docker]   docker system prune -af
  2  docker-logs    [docker]   docker logs -f --tail 100 <container>

# 只看某个标签下的片段
$ snip find --tag k8s

# 把第一个匹配结果复制到剪贴板
$ snip find docker-clean --copy
参数说明
-t, --tag按标签过滤
-c, --copy复制第一个结果到剪贴板
-i, --interactive进入交互式选择界面（方向键选择、回车确认）

snip sync

把本地片段库与配置中的 Git 远程仓库双向同步，在多台机器上共享片段。

shell
$ snip sync
↓ 拉取 3 个新片段
↑ 推送 1 个修改
✔ 同步完成

# 只预览变化，不实际执行
$ snip sync --dry-run
参数说明
--dry-run只显示将要发生的变化
--pull-only只拉取远程更新，不推送本地修改
--force冲突时以本地版本为准（谨慎使用）
使用前提 需先在配置中设置 sync.remote，并确保本机可以通过 SSH 或 HTTPS 访问该仓库。
