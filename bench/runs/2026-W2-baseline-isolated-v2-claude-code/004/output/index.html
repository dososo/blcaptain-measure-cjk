常见问题

改出来的周报会不会"编数据"？

不会。笔润只基于你提供的内容整理和润色，遇到缺少数据的地方会用 [待补充] 标出并提示你补充，而不是凭空捏造。

能保留我自己的写作风格吗？

可以。你可以上传几篇过往的周报或邮件，笔润会学习你的用词习惯，改写结果更像你本人写的。

我的工作内容会被泄露吗？

所有内容加密传输与存储，默认不用于模型训练，你可以随时一键删除历史记录。团队版支持私有化部署。

除了周报和邮件还能写什么？

日报、月度总结、述职报告、会议纪要、通知公告、工作群消息等常见职场文体都支持。
