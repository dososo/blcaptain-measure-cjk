常用系统账号

大部分系统都用统一账号（SSO）登录，用户名是你的邮箱前缀。只需记住一套密码。

系统用途登录方式开通方式
统一账号（SSO）所有内部系统的登录入口邮箱前缀 + 密码 + 双重验证入职当天由 IT 开通，首次登录需改密码
企业邮箱收发邮件、日历、会议邀请SSO自动开通
即时通讯日常沟通、群聊、视频会议SSO自动开通，手机端扫码登录

知识库团队文档、制度、操作手册SSO自动开通，部门空间需管理员授权
VPN在公司外访问内网SSO + 验证码在 IT 服务门户提交申请
代码仓库代码托管与评审（研发岗）SSO主管在 IT 服务门户审批后开通
会议室预订预订会议室和设备通过日历直接预订自动开通

账号安全：不要把密码告诉任何人，IT 也不会向你索要密码。收到可疑邮件或链接，先转发给 IT 服务台确认。忘记密码可以在 SSO 登录页自助重置。
