智能门锁使用说明

本页介绍三项常用操作：录入指纹、更换电池、恢复出厂设置。不同型号的按键名称和语音提示可能略有差异，请以随机附带的说明书为准。

壹

录入指纹

新锁首次使用时处于「初始状态」，任何指纹都能开门。录入第一个管理员后，门锁才进入正常安全模式。

录入前准备

  • 保持手指干净、干燥，不要有水、油或护手霜。
  • 擦净指纹采集窗口。
  • 建议每人录入 2 枚常用手指（如两只手的食指），以防一侧手指受伤。

操作步骤

  1. 触摸外面板数字区，唤醒门锁，键盘亮起。
  2. 按 * 再按 #（部分型号为长按内面板的「设置」键），进入管理菜单。
  3. 按语音提示验证管理员身份：输入管理员密码后按 #，或按压已录入的管理员指纹。初始状态下跳过此步。
  4. 选择「用户设置」→「添加用户」→「指纹」，并选择用户类型（管理员或普通用户）。
  5. 听到「请按手指」后，将手指平放在采集窗口，听到提示音后抬起。
  6. 重复按压 4–6 次，每次略微变换角度和位置，让中心、左右边缘都被采集到。
  7. 听到「录入成功」并报出用户编号，记下这个编号，方便日后删除。
  8. 按 * 逐级返回，或静置 10 秒自动退出菜单。
小技巧

录完后立即关门试开 3–5 次。如果识别偏慢，可对同一根手指再录一次，门锁会把两份模板一起比对。

注意

至少保留一名管理员，并牢记管理员密码。管理员信息丢失后只能恢复出厂设置，所有用户都需重新录入。

贰

更换电池

当开门时听到「电量低，请更换电池」或指示灯闪红，说明电量即将耗尽。低电提醒后通常还能开门约 100–200 次，但请尽快更换。

电池规格

干电池款4 节或 8 节 5 号（AA）碱性电池，请勿使用碳性电池或充电电池
锂电池款门锁自带可拆卸锂电池包，取下后用 USB-C 线充电，充满约 4–6 小时
续航参考正常使用约 8–12 个月；带视频猫眼的型号更短

操作步骤

  1. 在室内一侧找到内面板上方的电池盖（多数在把手上方）。
  2. 按住卡扣向上推或向下滑开电池盖；部分型号需用螺丝刀拧下 1 颗螺丝。
  3. 取出全部旧电池。请一次性全部更换，不要新旧混用。
  4. 按电池仓内 + − 标识装入新电池，方向装反门锁不会通电。
  5. 盖好电池盖，门锁会发出启动提示音。
  6. 用指纹或密码试开一次，确认工作正常。
换电池不会清空数据

指纹、密码等用户信息保存在断电不丢失的存储芯片里，换电池后无需重新录入。部分型号的时间设置可能需要重新校准。

电池耗尽、人在门外怎么办
  • 应急供电：外面板底部通常有 USB-C（或 Micro-USB）应急口，接上充电宝即可临时通电，然后正常用指纹或密码开门。
  • 机械钥匙：拨开外面板上的钥匙孔盖，用随附的机械钥匙开门。请把钥匙存放在门外可取到的地方（如车里、办公室），不要锁在屋内。
叁

恢复出厂设置

此操作会清空全部数据

所有指纹、密码、门卡、App 绑定关系都会被删除，且无法撤销。门锁回到初始状态后，任何指纹都能开门，请立即重新录入管理员。

适用场景

  • 忘记管理员密码，且无已录入的管理员指纹。
  • 房屋转租、出售，需要清除前任住户的信息。
  • 门锁系统异常，重启无效。

方法一：复位键（推荐）

  1. 保持门处于打开状态，人在室内操作，避免把自己锁在门外。
  2. 打开内面板电池盖，在电池仓附近找到标有「RESET」或「复位」的小孔或按钮。
  3. 用卡针或回形针长按复位键约 5 秒，直到听到「请输入初始密码」或「恢复出厂设置」提示。
  4. 按提示在外面板输入初始密码（常见为 123456，以说明书为准）并按 # 确认；部分型号无需此步。
  5. 听到「初始化成功」即完成，门锁会自动重启。

方法二：通过管理菜单

  1. 按 * # 进入管理菜单，验证管理员身份。
  2. 选择「系统设置」→「恢复出厂设置」。
  3. 按 # 确认，等待语音提示「初始化成功」。

复位后要做的事

  • 立即按「壹 录入指纹」的步骤重新添加管理员。
  • 重新设置开门密码，不要沿用初始密码。
  • 如使用手机 App，需在 App 中删除旧设备后重新配网绑定。

常见问题

指纹总识别失败擦净采集窗口；手指过干可哈口气再按；冬季手指脱皮时建议改用密码，或重新录入。
提示「系统锁定」连续验证失败 5 次后门锁会锁定约 3 分钟，等待后再试，或在室内用把手开门。
换完电池没反应检查电池方向和是否为碱性电池；确认电池盖内的排线插头没有松脱。
找不到复位键部分型号复位键在内面板背面，需拆下内面板；请查阅说明书或联系售后。
本说明为通用操作指引。具体按键组合、初始密码与电池规格因品牌型号而异，请以产品说明书或厂家客服答复为准。
