常见问题

完全没有基础，可以来上课吗？

当然可以。课表中标注「入门」的课程专为零基础学员设计，老师会提供动作替代方案。建议先从单次体验课开始。

需要自己带瑜伽垫吗？

不需要。教室提供瑜伽垫、瑜伽砖、伸展带等辅具，并定期消毒。你只需穿着舒适、方便活动的衣服即可。

怎么预约课程？取消有什么规定？

可通过工作室小程序提前 7 天预约。开课前 4 小时以上取消不扣次数；4 小时内取消或缺席，次卡扣除 1 次，月卡与年卡计 1 次爽约，当月累计 3 次将暂停预约 3 天。

办卡后可以转让或退款吗？

月卡与年卡可在有效期内转让 1 次（需支付 ¥100 手续费）。开卡 7 天内未上课可全额退款，其余情况按剩余天数或次数折算。

体验课后办卡有优惠吗？

体验课当天办理任意会籍，体验费可全额抵扣卡费。
