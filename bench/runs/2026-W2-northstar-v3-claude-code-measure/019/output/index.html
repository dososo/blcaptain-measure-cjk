用户服务 API

通过这组接口，你可以在自己的系统里创建、查询、修改和删除用户账号。所有接口都基于 HTTPS，请求和响应的正文都使用 JSON。

基础地址

https://api.example.com/v1

通用约定

  • 请求正文的 Content-Type 必须是 application/json，字符编码为 UTF-8。
  • 时间字段统一使用 ISO 8601 格式的 UTC 时间，例如 2026-10-26T03:12:45Z。
  • 用户 ID 是以 usr_ 开头的字符串，长度固定为 24 位，请不要按数字解析。
  • 每个响应都带有 X-Request-Id 头。联系技术支持时附上它，可以更快定位问题。

鉴权

所有接口都需要鉴权。流程分两步：先用控制台里拿到的 API 密钥换取访问令牌，再在每次请求里携带这个令牌。

第一步：获取访问令牌

在控制台的“开发者设置”页面创建应用，会得到 client_id 和 client_secret。用它们调用令牌接口：

POST /oauth/token
请求示例 · curl
curl -X POST https://api.example.com/v1/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "client_credentials",
    "client_id": "app_7f3k2m9q",
    "client_secret": "sk_live_••••••••",
    "scope": "users:read users:write"
  }'
响应 · 200 OK
{
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 7200,
  "scope": "users:read users:write"
}

第二步：在请求头里携带令牌

把令牌放进 Authorization 请求头，前面加上 Bearer 和一个空格：

请求头
Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...

权限范围

申请令牌时用 scope 声明需要的权限，多个权限之间用空格分隔。只申请业务真正用到的权限。

scope允许的操作
users:read查询用户
users:write创建、更新用户
users:delete删除用户。需要在控制台单独开通

令牌有效期

访问令牌有效期为 2 小时（expires_in 的单位是秒）。过期后接口返回 401，错误码为 token_expired，此时重新执行第一步即可。建议在过期前 5 分钟主动刷新，避免请求失败。

安全提示：不要把 client_secret 写进浏览器或手机客户端的代码里。令牌接口只应由你的服务端调用。

错误格式

请求失败时，接口返回 4xx 或 5xx 状态码，响应正文统一为下面的结构。程序里请根据 code 判断错误类型，message 只用于排查，内容可能调整。

错误响应 · 422 Unprocessable Entity
{
  "error": {
    "code": "invalid_field",
    "message": "email 格式不正确",
    "field": "email",
    "request_id": "req_01HF8Z3K2Q9V"
  }
}
状态码code含义
400bad_request请求正文不是合法的 JSON
401unauthorized没有携带令牌，或令牌无效
401token_expired令牌已过期，需要重新获取
403insufficient_scope令牌缺少该接口需要的权限范围
404user_not_found用户不存在，或已被删除
409email_taken邮箱已被其他用户使用
422invalid_field字段校验失败，field 指出是哪个字段
429rate_limited请求过于频繁，按 Retry-After 头等待后重试

创建用户

POST /users 需要 users:write

新建一个用户。邮箱在整个应用内唯一，重复创建会返回 409。

请求正文

字段类型必填说明
emailstring必填登录邮箱，最长 254 个字符
namestring必填显示名称，1 到 64 个字符
phonestring可选手机号，E.164 格式，例如 +8613800138000
rolestring可选member 或 admin，默认 member
请求示例 · curl
curl -X POST https://api.example.com/v1/users \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "lin.wei@example.com",
    "name": "林薇",
    "role": "member"
  }'
响应 · 201 Created
{
  "id": "usr_9Kx2Lm7Qp4Rt8Vw1Yz3Bc6",
  "email": "lin.wei@example.com",
  "name": "林薇",
  "phone": null,
  "role": "member",
  "status": "active",
  "created_at": "2026-10-26T03:12:45Z",
  "updated_at": "2026-10-26T03:12:45Z"
}

查询用户

GET /users/{id} 需要 users:read

按 ID 获取单个用户的完整信息。已删除的用户返回 404。

路径参数

参数类型说明
idstring用户 ID，以 usr_ 开头
请求示例 · curl
curl https://api.example.com/v1/users/usr_9Kx2Lm7Qp4Rt8Vw1Yz3Bc6 \
  -H "Authorization: Bearer $TOKEN"
响应 · 200 OK
{
  "id": "usr_9Kx2Lm7Qp4Rt8Vw1Yz3Bc6",
  "email": "lin.wei@example.com",
  "name": "林薇",
  "phone": null,
  "role": "member",
  "status": "active",
  "created_at": "2026-10-26T03:12:45Z",
  "updated_at": "2026-10-26T03:12:45Z"
}

响应字段

字段类型说明
idstring用户 ID
emailstring登录邮箱
namestring显示名称
phonestring | null手机号，没有填写时为 null
rolestringmember 或 admin
statusstringactive（正常）或 suspended（已停用）
created_atstring创建时间
updated_atstring最后修改时间

更新用户

PATCH /users/{id} 需要 users:write

只修改请求正文里出现的字段，没有出现的字段保持不变。把 phone 设为 null 可以清空手机号。

请求正文

字段类型说明
emailstring新的登录邮箱，不能与其他用户重复
namestring新的显示名称
phonestring | null新的手机号，传 null 表示清空
rolestringmember 或 admin
statusstring设为 suspended 可停用账号，停用后无法登录
请求示例 · curl
curl -X PATCH https://api.example.com/v1/users/usr_9Kx2Lm7Qp4Rt8Vw1Yz3Bc6 \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "林薇（产品部）",
    "phone": "+8613800138000"
  }'
响应 · 200 OK
{
  "id": "usr_9Kx2Lm7Qp4Rt8Vw1Yz3Bc6",
  "email": "lin.wei@example.com",
  "name": "林薇（产品部）",
  "phone": "+8613800138000",
  "role": "member",
  "status": "active",
  "created_at": "2026-10-26T03:12:45Z",
  "updated_at": "2026-10-26T08:40:02Z"
}

删除用户

DELETE /users/{id} 需要 users:delete

删除后用户立即无法登录，查询会返回 404。数据保留 30 天，期间可以联系技术支持恢复；30 天后永久清除。只想暂时禁止登录的话，请用更新接口把 status 设为 suspended。

请求示例 · curl
curl -X DELETE https://api.example.com/v1/users/usr_9Kx2Lm7Qp4Rt8Vw1Yz3Bc6 \
  -H "Authorization: Bearer $TOKEN"
响应 · 204 No Content
# 成功时没有响应正文
