✳ 周末出逃计划HANGZHOU · WEEKEND GUIDE / 01

把周末，交给湖光与茶香

杭州两天一夜

一日西湖慢游，一日山野吸氧。

2D / 1N慢一点 · 刚刚好
DAY 01

沿着西湖，把时间放慢

湖畔散步 / 老街寻味
09:00 · 上午

断桥 → 白堤 → 孤山

走进湖光山色
在湖边留一张合照

14:00 · 午后

北山街 → 湖滨

沿湖散步，找间咖啡店
把下午留给西湖

18:00 · 入夜

河坊街 → 南宋御街

逛老街，吃一碗片儿川
在烟火气里结束一天

西湖只选北线慢慢逛；湖滨到河坊街可乘车，给双脚放个假。

DAY 02

走进茶山，收集一整片绿

茶香入山 / 溪边漫步
09:00 · 上午

龙井村

沿村道看看层层茶园
坐下来，喝一杯龙井

12:00 · 午后

九溪十八涧 → 九溪烟树

午饭后顺着溪流往下走
为树影和流水停一停

16:00 · 返程

九溪出口 → 车站

乘车接驳地铁去车站
带着满格绿意回家

第二天为半日山路步行，穿防滑鞋；返程建议预留至少 2 小时。
