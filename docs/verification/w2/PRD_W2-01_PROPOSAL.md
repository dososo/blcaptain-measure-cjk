# PRD 变更提案：W2-01（更正「优先于 measure.css」的说法）

**状态：用户已确认（2026-10-25）。** 原话：「确认 W2-01 按提案更正 PRD §5.1 和 §7.4 的说法，并新增附录 C22。」已按本提案修改 `docs/PRD.md`。

**依据：** AUDIT_W2_C20 W2-01。`measure.css` 用 `:where(:lang(zh))` 等选择器**直接作用在每个中文元素上**。按 CSS 层叠规则，直接作用在元素上的声明（哪怕在最低的层里），优先于从祖先元素继承下来的值。所以：
- 写在 `body` 上的 `line-height: 1.4`，传不到中文段落，会被 measure.css 的 1.75 盖掉；
- C20 把 `line-break: strict` 挪到每个中文元素上以后，`body { line-break: anywhere; }` 对中文也不再生效。

现在 PRD 的两处说法「不会覆盖用户的任何样式」「页面上不分层的样式，永远优先于 measure.css」只对**直接写在中文元素上**的样式成立。

## 改动 1：§5.1

**现在：**

> ……全部放在 `@layer measure` 里、优先级为 0；在入口 CSS 第一行写 `@layer measure;` 时，它不会覆盖用户的任何样式（包括分层样式）；……

**改为：**

> ……全部放在 `@layer measure` 里、优先级为 0；在入口 CSS 第一行写 `@layer measure;` 时，用户直接写在元素上的样式（包括分层样式）都优先于它；但写在祖先元素上、靠继承传下来的值会被它覆盖（见 §7.4）；……

## 改动 2：§7.4「优先级与层」第一条

**现在：**

> - 页面上不分层的样式，永远优先于 `measure.css`。

**改为：**

> - 页面上不分层的样式，只要直接作用在中文元素上，就优先于 `measure.css`。
> - **例外：继承来的值。** `measure.css` 直接作用在每个中文元素上，直接作用的声明优先于继承值。所以写在 `body` 等祖先元素上的 `line-height`、`line-break`、`text-autospace` 等，传不到中文元素；要改这些属性，请写在中文元素或 `:lang(zh)` 上。

## 改动 3：附录 C

新增一行：C22，更正 §5.1、§7.4 关于优先级的说法（AUDIT_W2_C20 W2-01）。
