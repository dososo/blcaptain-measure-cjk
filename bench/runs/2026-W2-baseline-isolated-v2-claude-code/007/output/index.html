用 Python 处理 Excel 报表的 5 个技巧

2026 年 10 月 25 日 阅读约 10 分钟

每周一早上打开十几个 Excel 文件、复制粘贴、做透视表、调格式……这种重复劳动最适合交给 Python。本文整理了我在报表自动化中最常用的 5 个技巧，每个都附可直接运行的代码。

示例基于 pandas 2.x 和 openpyxl 3.x。假设我们有一批销售明细文件，每个文件包含 日期、区域、产品、销量、单价 等列。

01精准读取：只拿你需要的数据

很多人直接 pd.read_excel("file.xlsx") 一把梭，结果遇到表头不在第一行、编号被读成浮点数、日期变成数字等问题。read_excel 的几个参数能在读取阶段就把数据整理干净：

read_clean.py
import pandas as pd

df = pd.read_excel(
    "sales_2026_10.xlsx",
    sheet_name="明细",            # 按名称指定工作表，也可用索引 0
    skiprows=2,                    # 跳过顶部的标题和说明行
    usecols="A:F",                 # 只读需要的列，大文件能明显提速
    dtype={"订单号": str},          # 防止 "000123" 被读成 123.0
    parse_dates=["日期"],           # 直接解析为 datetime
    na_values=["-", "N/A", "无"],   # 把业务上的“空值”统一成 NaN
)

# 一次读取所有工作表：返回 {sheet_name: DataFrame}
all_sheets = pd.read_excel("sales_2026_10.xlsx", sheet_name=None)
for name, sheet in all_sheets.items():
    print(name, sheet.shape)
小贴士如果 Excel 里的列名带有空格或换行，读取后立刻执行 df.columns = df.columns.str.strip()，能省掉后面很多 KeyError。

02批量合并：多文件、多 Sheet 一次搞定

各区域每月交上来一个文件，要汇总成一张总表？用 pathlib 遍历文件，再用 pd.concat 合并。关键在于合并时记录来源，方便之后追溯问题数据。

merge_files.py
from pathlib import Path
import pandas as pd

frames = []
for path in sorted(Path("reports").glob("*.xlsx")):
    if path.name.startswith("~$"):      # 跳过 Excel 打开时生成的临时文件
        continue
    sheets = pd.read_excel(path, sheet_name=None)
    for sheet_name, df in sheets.items():
        df["来源文件"] = path.name
        df["来源Sheet"] = sheet_name
        frames.append(df)

merged = pd.concat(frames, ignore_index=True)

# 合并后做基本清洗
merged = (
    merged
    .dropna(subset=["订单号"])            # 去掉没有订单号的空行
    .drop_duplicates(subset=["订单号"])   # 同一订单出现在多个文件时去重
)
print(f"共合并 {len(frames)} 张表，{len(merged)} 行数据")
注意各文件的列名如果不完全一致，concat 会产生大量 NaN 列。可以先定义一个映射字典，用 df.rename(columns=mapping) 统一列名后再合并。

03透视汇总：用 pivot_table 代替手工透视表

Excel 透视表能做的，pivot_table 都能做，而且可以复现、可以版本管理。下面按区域和月份汇总销售额，并带上合计行：

pivot.py
merged["销售额"] = merged["销量"] * merged["单价"]
merged["月份"] = merged["日期"].dt.to_period("M").astype(str)

pivot = pd.pivot_table(
    merged,
    index="区域",
    columns="月份",
    values="销售额",
    aggfunc="sum",
    fill_value=0,
    margins=True,           # 自动添加“合计”行和列
    margins_name="合计",
)

# 多指标汇总：用 groupby + agg 的具名聚合，列名一目了然
summary = (
    merged.groupby(["区域", "产品"])
    .agg(
        订单数=("订单号", "nunique"),
        总销量=("销量", "sum"),
        销售额=("销售额", "sum"),
        平均单价=("单价", "mean"),
    )
    .round(2)
    .sort_values("销售额", ascending=False)
    .reset_index()
)

具名聚合（named aggregation）的写法比传字典更清晰，输出的列名就是你想要的中文报表列名，不需要再 rename。

04体面导出：多 Sheet + 列宽 + 冻结窗格

df.to_excel() 导出的文件能用，但不好看：列宽挤在一起、表头没有样式。用 ExcelWriter 一次写入多个 Sheet，再借助 openpyxl 调整格式，老板打开就能直接看。

export.py
from openpyxl.styles import Font, PatternFill, Alignment
from openpyxl.utils import get_column_letter

HEADER_FILL = PatternFill("solid", fgColor="1D7A4F")
HEADER_FONT = Font(bold=True, color="FFFFFF")

def beautify(ws):
    # 表头样式
    for cell in ws[1]:
        cell.fill = HEADER_FILL
        cell.font = HEADER_FONT
        cell.alignment = Alignment(horizontal="center", vertical="center")
    # 按内容自动估算列宽（中文字符按 2 个宽度计）
    for col_idx, column in enumerate(ws.columns, start=1):
        width = max(
            sum(2 if ord(ch) > 127 else 1 for ch in str(c.value or ""))
            for c in column
        )
        ws.column_dimensions[get_column_letter(col_idx)].width = min(width + 4, 50)
    ws.freeze_panes = "B2"      # 冻结首行和首列
    ws.auto_filter.ref = ws.dimensions

with pd.ExcelWriter("销售周报.xlsx", engine="openpyxl") as writer:
    pivot.to_excel(writer, sheet_name="区域月度汇总")
    summary.to_excel(writer, sheet_name="产品明细", index=False)
    merged.to_excel(writer, sheet_name="原始数据", index=False)

    for ws in writer.book.worksheets:
        beautify(ws)
引擎优点适用场景
openpyxl可读可写，能修改已有文件在模板上填数、二次加工
xlsxwriter写入快，图表和格式功能丰富从零生成新报表

05条件格式与图表：让数据自己说话

报表的价值在于让人一眼看到重点。openpyxl 支持写入原生的 Excel 条件格式和图表——它们不是图片，用户在 Excel 中修改数据后会自动更新。

highlight.py
from openpyxl import load_workbook
from openpyxl.formatting.rule import ColorScaleRule, CellIsRule
from openpyxl.chart import BarChart, Reference
from openpyxl.styles import PatternFill

wb = load_workbook("销售周报.xlsx")
ws = wb["产品明细"]
last_row = ws.max_row

# 1) 销售额列（E 列）加三色色阶：低-红，中-黄，高-绿
ws.conditional_formatting.add(
    f"E2:E{last_row}",
    ColorScaleRule(
        start_type="min", start_color="F8696B",
        mid_type="percentile", mid_value=50, mid_color="FFEB84",
        end_type="max", end_color="63BE7B",
    ),
)

# 2) 平均单价低于 100 的单元格标红底
ws.conditional_formatting.add(
    f"F2:F{last_row}",
    CellIsRule(operator="lessThan", formula=["100"],
               fill=PatternFill("solid", fgColor="FFC7CE")),
)

# 3) 插入柱状图：前 10 名的销售额
chart = BarChart()
chart.title = "销售额 Top 10"
chart.y_axis.title = "销售额（元）"
data = Reference(ws, min_col=5, min_row=1, max_row=min(11, last_row))
cats = Reference(ws, min_col=2, min_row=2, max_row=min(11, last_row))
chart.add_data(data, titles_from_data=True)
chart.set_categories(cats)
chart.width, chart.height = 18, 9
ws.add_chart(chart, "H2")

wb.save("销售周报.xlsx")
小贴士openpyxl 不会计算公式。如果你写入了 =SUM(...) 之类的公式又需要在 Python 里读到结果，要么在 pandas 里先算好再写入，要么用 load_workbook(..., data_only=True) 读取一个已被 Excel 保存过的文件。

总结

把这 5 步串起来，就是一条完整的报表流水线：

  • 读：用 read_excel 的参数在入口处清洗数据；
  • 合：glob + concat 批量合并，并保留来源信息；
  • 算：pivot_table 和具名聚合替代手工透视；
  • 写：ExcelWriter 多 Sheet 导出，统一美化格式；
  • 亮：条件格式与原生图表突出重点。

把脚本放进定时任务（cron 或 Windows 任务计划），每周一早上报表就已经躺在共享盘里了。
