上班族 · 早餐手记

十分钟
好好吃早饭

四个做法，按耗时从短到长。

  1. 壹

    隔夜燕麦杯2 分钟

    前一晚燕麦 40g 加牛奶 150ml、酸奶一勺，冷藏。早上铺香蕉片和坚果即食。

  2. 贰

    微波炉蒸蛋5 分钟

    两个蛋加 1.5 倍温水打匀，盖碗留小孔，中火 2 分半，淋点生抽香油。

  3. 叁

    煎蛋芝士吐司6 分钟

    平底锅煎蛋，同时烘两片吐司，夹芝士、生菜，对角一切带着走。

  4. 肆

    番茄鸡蛋面8 分钟

    番茄丁炒出汁加水烧开，下挂面，快熟时淋蛋液，撒盐和葱花。

收藏备用，明早就试一个 早
