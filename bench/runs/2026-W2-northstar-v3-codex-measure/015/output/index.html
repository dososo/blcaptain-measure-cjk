GOOD TO KNOW

还有一些，你可能想了解的

把计费规则说清楚，安心写下每一行代码。

免费额度用完后，会停止服务吗？+

示例方案中，账户余额充足时将继续服务，超出免费额度的部分按页面单价计费。你可以设置预算提醒，及时了解用量变化。

不足一千次调用，怎么计费？+

按实际调用次数计算，不向上取整到千次。例如通用 API 超出免费额度 200 次，费用为 200 ÷ 1,000 × 0.50，即 0.10 元。

免费额度可以累积到下个月吗？+

免费额度在每个自然月首日重置，未使用部分不结转。三类 API 的额度独立计算，不互相抵扣。

调用失败也会收费吗？+

只对成功返回结果的请求计费。鉴权失败、限流和服务端错误请求均不扣除免费额度，也不产生费用。
