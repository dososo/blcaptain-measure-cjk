# 中文 AI 味反模式（A 系列）

**状态：** 完整档（`lint --render`）已检查 A01（紫色、蓝紫渐变背景）和 A11（加粗比例超过 15%）；其余条目暂时只有说明文档。全部规则都是 warn。涉及文案的条目只提示，不自动改写。

| ID | 反模式 | 为什么是 AI 味 | 更好的做法 |
|---|---|---|---|
| <a id="a01"></a>A01 | 紫色、蓝紫色渐变背景 | 生成式设计里最常见的默认配色 | 从真实素材（产品照片、品牌物料）里取色 |
| <a id="a02"></a>A02 | 玻璃拟态：`backdrop-filter: blur` 加半透明卡片 | 层层叠叠的毛玻璃，没有信息层级 | 用实色底和清楚的分隔 |
| <a id="a03"></a>A03 | 霓虹光晕、发光描边 | 多层彩色阴影，喧宾夺主 | 去掉装饰性的发光 |
| <a id="a04"></a>A04 | 用 emoji 当图标 | 在不同系统上显示不一致，显得随意 | 用线性图标，或者干脆不用图标 |
| <a id="a05"></a>A05 | 大圆角加重阴影的「SaaS 模板脸」 | 千篇一律 | 收小圆角，减轻阴影 |
| <a id="a06"></a>A06 | 翻译腔大标题：赋能、引领、打造、一站式、全方位、助力、开启新篇章 | 像机器翻译的英文营销文案 | 说清楚具体做什么，比如「帮小团队 20 分钟对完账」 |
| <a id="a07"></a>A07 | 假中文占位文案：「这里是标题」「示例文本」 | 交付时还没换成真内容 | 用真实或接近真实的内容 |
| <a id="a08"></a>A08 | 三列「功能亮点」卡片连续出现 | 图标、粗标题、两行描述，模板感很重 | 按内容的重要程度安排版面 |
| <a id="a09"></a>A09 | 把英文的大写小标题（eyebrow）机械套到中文上 | 中文没有大小写 | 用字号、字重或颜色来区分 |
| <a id="a10"></a>A10 | 中英文字重不一致：西文 600，中文字体只有 400 | 中英文混排时一粗一细 | 选有对应字重的中文字体，或者统一字重 |
| <a id="a11"></a>A11 | 每段都加粗关键词，加粗的比例超过 15% | 处处强调，等于没有强调 | 一屏只强调一两处 |
| <a id="a12"></a>A12 | 中文标题照搬英文 hero 的无衬线体和负字距 | 汉字挤在一起 | 字距 0 到 0.05em，见 T07 |

## 完整档怎么判断 A01、A11

- **A01：** 检查 `html`、`body`，以及面积超过首屏 15% 的元素和它们的 `::before`、`::after`。背景是渐变时，把渐变里的每个颜色画到画布上取 sRGB 值；只要有一个颜色是紫色、蓝紫（色相 250°–320°，饱和度不低于 25%，亮度 15%–90%），或者是靛蓝（色相 235°–250°，饱和度 60%–95%，亮度 40%–75%），就报 warn。常见的蓝色、纯蓝、藏青都不报。
- **A11：** 统计 20 个汉字以上、本身不是粗体的正文段落（`p`、`li`）。加粗（字重 ≥ 600）的汉字超过全部汉字的 15%，并且至少一半的段落（不少于 2 段）都有加粗时，报 warn。
