云南 · 大理

在大理住了两周

本来只打算待三天，结果退了两次返程票。这是十四天里记下的一些事：风、湖、早市，还有慢下来的日子。

九月下旬至十月初 · 住古城人民路附近

落脚古城

第一天至第三天

从昆明坐动车过来，两个小时出头。出了大理站打车进古城，司机一路指着窗外说：“左边是苍山，右边是洱海，大理就夹在中间。”后来才发现，这句话几乎能解释这里的一切——天气、风向、街道的走向，连人的脾气都跟着山和湖走。

客栈是一座三坊一照壁的白族老院子，院里种着一棵三角梅，开得没什么节制。老板娘姓杨，每天早上在天井里煮一壶普洱，谁起来了谁就去倒一杯。头三天我几乎没出古城，就在人民路、复兴路和洋人街之间来回走，走累了就找个台阶坐着看人。

古城的水沟是从苍山上引下来的，顺着石板路往下淌，夜里很安静的时候能听到水声。这是我对大理最早的印象：一座有水声的城。

早市与一碗饵丝

几乎每天早上

住久了，作息也被改了过来。每天七点多起床，去古城东门外的菜市场转一圈。卖菜的阿嬢戴着白族头饰，菜摊上摆着我叫不出名字的野菜，九月正好赶上菌子季的尾巴，见手青、鸡枞、干巴菌堆在竹筐里，价格一天一个样。

吃了两周，最后记住的几样是：

  • 烧饵块：米做的饼在炭火上烤软，抹上甜酱、辣酱，夹油条或者乳扇，卷起来边走边吃。
  • 凉鸡米线：鸡丝、花生碎、酸辣汁，夏天的尾巴里吃最合适。
  • 喜洲粑粑：分甜咸两种，刚出炉的时候外壳是酥的，烫得要换手拿。
  • 酸辣鱼：洱海边的做法，木瓜酸压住了鱼腥，配一碗白饭就够了。

市场口有一家饵丝铺，老板记性很好，第三次去的时候就不用我开口了：“还是小碗，不要香菜？”那一刻有点被当成本地人的错觉。

沿着洱海骑车

第五天

环洱海一圈一百多公里，我没那个体力，只骑了西岸的生态廊道，从才村一路往北到喜洲。路是专门修的慢行道，汽车开不进来，一边是稻田，一边是湖。

那天风很大。大理的风出了名，“下关风”排在“风花雪月”的第一个字，并不是随便写的。逆风骑的时候几乎是在原地蹬，顺风的时候又像被人推着走。中途在磻溪村停下来歇脚，湖边的水杉立在浅水里，有人支着三脚架等日落，我坐在旁边吃了一个苹果，一直等到天边烧成橘红色。

湖面上的光一点点暗下去，苍山顶上的云却还亮着。那是我在大理见过最安静的十分钟。

喜洲和周城

第六天至第七天

喜洲比古城安静得多。镇子里保留着不少民国时期商帮的老宅，严家大院的雕花门窗看得我站了很久。镇子外面就是稻田，九月底稻子正黄，田埂上有人在拍婚纱照，也有老人赶着牛慢慢走过去。

第二天去了不远处的周城，看白族扎染。作坊里的阿嬢先教我用针线把布扎起来，再一起放进板蓝根煮出来的染缸里。拆线的时候才知道效果，我那块歪歪扭扭的，像一朵没开好的花，但她说：“扎染就是这样，每一块都不一样。”这块布后来一直挂在客栈房间的窗边。

上苍山

第九天

坐感通索道上山，再沿着玉带路往北走。玉带路修在半山腰，海拔两千六百米左右，几乎是平的，走起来不累，但一侧就是山谷，往下看能望见整个洱海和坝子里的村子。

山上的天气变得很快。上午还是晴的，走到一半云就从山谷里涌上来，几分钟之内什么都看不见了，只剩脚下的石板和身边的松树。又过了一阵，云散开，洱海重新露出来，像刚洗过一样。下山的路上遇到一位每周都来走一趟的大叔，他说住在大理最大的好处，就是山永远在那里。

雨、晚霞和慢下来的日子

第十天至第十三天

九月底还没完全出雨季，经常是下午两三点来一场雨，半小时就停。雨后的古城很干净，石板路发亮，天边常常会有晚霞。后来我养成了一个习惯：一下雨就钻进最近的咖啡馆或者书店，等雨停了再出门看天。

这几天什么景点都没去。上午在院子里看书，下午去古城里的一家旧书店翻书，晚上跟客栈里的其他住客一起吃饭。有一位在这里住了三年的画画的姑娘，一位刚辞职来“想清楚”的程序员，还有一对退休后开着车走遍云南的夫妻。大家聊的都是很小的事：今天哪家的菌子新鲜，明天会不会下雨，周末要不要去沙溪。

我渐渐明白为什么有那么多人来了就不想走。不是因为这里有多少非看不可的东西，而是这里的节奏允许你什么都不做，也不觉得心慌。

离开

第十四天

走的那天早上，杨嬢嬢照例煮了一壶普洱，往我包里塞了两块喜洲粑粑。去车站的路上又经过那条水沟，水声还和第一天一样。

两周其实很短，短到很多地方都没去：没去双廊，没去沙溪，也没赶上三月街。但我好像也不太遗憾——总得给下次留一点理由。

写于返程的动车上。照片太多，以后再慢慢整理。
