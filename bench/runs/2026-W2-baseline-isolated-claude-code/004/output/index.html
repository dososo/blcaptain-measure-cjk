常见问题

你可能想知道

改写后会不会编造我没做过的事？

不会。润笔只重组和润色你提供的内容。当它认为某处需要补充数据时，会用占位符标出并提示你填写，而不是自己编造。

我的周报和邮件内容安全吗？

内容传输全程加密，默认不保存你的草稿，也不会用于模型训练。企业版支持私有化部署。

能按我们公司的周报格式输出吗？

可以。上传一份过往周报或模板，润笔会学习其结构与用语，之后的改写都会保持一致。

在哪里可以使用？

支持网页版、浏览器插件，以及常见邮箱和在线文档的侧边栏插件，选中文字即可改写。
