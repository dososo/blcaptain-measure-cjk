开始之前 · 请准备 Node.js 20+ 和一个喜欢的终端。支持 macOS、Windows 和 Linux。
01

安装 Flow CLI

选择你熟悉的包管理器，全局安装后即可使用 flow 命令。

$npm install -g @flow-cli/core

安装后运行 flow --version，查看当前版本，确认安装成功。

02

按你的习惯配置

初始化项目后，编辑根目录的 flow.config.json。默认配置就能开始，也可以按需调整。

flow.config.json
{
  "name": "my-project",
  "port": 3000,
  "outDir": "dist"
}

port 指定本地开发端口，outDir 指定构建产物目录。

03

三个命令，即刻出发

从创建到开发，再到构建。你的日常工作流，都在这里。

flow init

创建项目，生成目录结构与默认配置。

01 / 创建
$flow init my-project

flow dev

进入项目，启动本地开发服务，修改实时生效。

02 / 开发
$cd my-project && flow dev

flow build

在项目目录中构建，产物输出至 dist 目录。

03 / 构建
$flow build
准备好开始了吗？复制第一行命令，开启你的工作流
