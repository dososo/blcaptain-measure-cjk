下载的素材可以用于商业项目吗？

专业版支持个人商业项目及客户交付；团队版的商用授权覆盖已购买席位的团队成员。免费版仅限个人非商业项目。具体使用范围以每份素材附带的授权说明为准，素材本身不可直接转售或重新分发。

我可以随时升级或取消会员吗？

可以随时申请升级方案。取消续订后，已付款的会员权益会保留至当前计费周期结束，之后不再续费。取消续订不会退还当前周期的费用。

团队版如何计算人数和费用？

团队版 3 人起订。年付为每人每月 ¥79，按年一次支付；3 人团队合计 ¥2,844 / 年。月付为每人每月 ¥109，3 人团队合计 ¥327 / 月。每位成员拥有独立账号，管理员可统一分配席位。
