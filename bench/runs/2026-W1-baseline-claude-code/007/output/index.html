用 Python 处理 Excel 报表的 5 个技巧

2026 年 10 月 25 日约 8 分钟读完pandas · openpyxl

每月底对着十几个 Excel 复制粘贴、调列宽、标红，这活儿交给 Python 就行。下面 5 个技巧覆盖了从「读进来」到「交出去」的整条链路，代码都能直接改改就用。

目录

  1. 一次读完所有工作表
  2. 批量合并一个文件夹的报表
  3. 用透视表代替手工汇总
  4. 导出时顺手调好格式
  5. 用条件格式标出异常值

先装好两个库（本文基于 pandas 2.x 与 openpyxl 3.1）：

pip install pandas openpyxl

技巧 一一次读完所有工作表

很多报表按月分 sheet：「1月」「2月」……一个个 read_excel 太啰嗦。把 sheet_name 设成 None，pandas 会返回一个字典，键是表名，值是 DataFrame，再用 concat 一把拼起来。

import pandas as pd

# sheet_name=None：读取全部工作表，返回 {表名: DataFrame}
sheets = pd.read_excel(
    "2026_sales.xlsx",
    sheet_name=None,
    usecols="A:F",                  # 只读需要的列，快且省内存
    dtype={"订单号": str},           # 防止 00123 被读成 123
)

# 字典的键会变成索引的一层，顺手转成一列「month」
df = (
    pd.concat(sheets, names=["month", "row"])
      .reset_index(level="month")
      .reset_index(drop=True)
)
print(df.head())

注意订单号、身份证号、邮编这类「长得像数字的文本」一定要用 dtype=str 指定，否则前导零会丢、长数字会变成科学计数法。

技巧 二批量合并一个文件夹的报表

各分公司各交一份格式相同的表，要合成总表。用 pathlib 遍历文件夹，读的时候用 assign 加一列来源，后面出问题能追溯到是哪个文件。

from pathlib import Path
import pandas as pd

frames = []
for f in sorted(Path("reports").glob("*.xlsx")):
    if f.name.startswith("~$"):     # 跳过 Excel 打开文件时生成的临时锁文件
        continue
    frames.append(pd.read_excel(f).assign(source=f.stem))

df = pd.concat(frames, ignore_index=True)
print(f"共合并 {len(frames)} 个文件，{len(df)} 行")

注意别在循环里反复 df = pd.concat([df, new])，每次都会复制整张表，文件一多就慢得离谱。先攒进列表，最后 concat 一次。

技巧 三用透视表代替手工汇总

Excel 里拖来拖去的数据透视表，在 pandas 里一行 pivot_table 就能搞定，还自带合计行列。

summary = pd.pivot_table(
    df,
    index="region",       # 行：大区
    columns="month",      # 列：月份
    values="amount",      # 值：销售额
    aggfunc="sum",
    fill_value=0,
    margins=True,         # 加上合计行和合计列
    margins_name="合计",
)

如果要同时出多个指标（总额、单数、客单价），用 groupby 加命名聚合更清楚：

stats = (
    df.groupby("region")
      .agg(
          total=("amount", "sum"),
          orders=("订单号", "nunique"),
      )
      .assign(avg_price=lambda t: (t.total / t.orders).round(2))
      .sort_values("total", ascending=False)
)

技巧 四导出时顺手调好格式

直接 to_excel 出来的表列宽挤成一团、数字没有千分位，领导打开第一眼就皱眉。用 ExcelWriter 拿到 openpyxl 的工作表对象，在保存前把冻结窗格、筛选、列宽、数字格式一次设好。

# 去掉列轴名，避免 pandas 多写一行表头
out = summary.rename_axis(columns=None)

with pd.ExcelWriter("summary.xlsx", engine="openpyxl") as writer:
    out.to_excel(writer, sheet_name="汇总")
    ws = writer.sheets["汇总"]

    ws.freeze_panes = "B2"               # 冻结首行首列
    ws.auto_filter.ref = ws.dimensions     # 给表头加筛选按钮

    # 按内容估算列宽：中文字符按 2 个宽度算
    for col in ws.iter_cols():
        width = max(
            sum(2 if ord(ch) > 127 else 1 for ch in str(c.value or ""))
            for c in col
        )
        ws.column_dimensions[col[0].column_letter].width = width + 2

    # 数值区域加千分位
    for row in ws.iter_rows(min_row=2, min_col=2):
        for cell in row:
            cell.number_format = "#,##0.00"

注意number_format 只改显示，不改值。单元格里存的依然是数字，求和、筛选都不受影响——这比在 pandas 里先格式化成字符串再导出好得多。

技巧 五用条件格式标出异常值

与其手动把低于目标的数字涂红，不如写成 Excel 原生的条件格式。好处是：别人改了数，颜色会跟着自动变。

from openpyxl import load_workbook
from openpyxl.formatting.rule import CellIsRule, ColorScaleRule
from openpyxl.styles import Font, PatternFill

wb = load_workbook("summary.xlsx")
ws = wb["汇总"]

# 数据区：去掉表头、首列，以及最后的「合计」行和列
last = ws.cell(row=ws.max_row - 1, column=ws.max_column - 1).coordinate
data_range = f"B2:{last}"

# 规则一：色阶，数值越大颜色越深
ws.conditional_formatting.add(
    data_range,
    ColorScaleRule(start_type="min", start_color="F8F4EC",
                   end_type="max", end_color="D9A38F"),
)

# 规则二：低于 10000 的标红加粗
red_fill = PatternFill(start_color="FFC7CE", end_color="FFC7CE", fill_type="solid")
ws.conditional_formatting.add(
    data_range,
    CellIsRule(operator="lessThan", formula=["10000"],
               font=Font(color="9C0006", bold=True), fill=red_fill),
)

wb.save("summary.xlsx")

注意formula 要传字符串列表，写的是 Excel 公式语法。阈值想放在某个单元格里由用户自己调，可以写成 ["$J$1"]（绝对引用）。

小结一条龙流水线

  • 读：sheet_name=None 一次读全，dtype=str 保护编号列。
  • 合：先攒列表再一次 concat，加来源列方便追溯。
  • 算：pivot_table 出交叉表，groupby().agg() 出多指标。
  • 写：ExcelWriter 里设冻结、筛选、列宽、数字格式。
  • 标：用条件格式代替手动涂色，数据变了颜色自动跟着变。

把这五步串成一个脚本，每月只要把新文件丢进 reports/ 文件夹，跑一下就出报表。
