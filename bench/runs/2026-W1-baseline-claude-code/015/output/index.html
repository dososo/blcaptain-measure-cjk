    计费规则

    先扣免费额度
    每个接口的免费额度独立计算，每月 1 日 00:00（UTC+8）重置，当月未用完不结转。
    阶梯累进
    扣除免费额度后的调用量按档累进计价：前 100 万次按第一档，100 万至 1,000 万次部分按第二档，其余按第三档。
    什么算一次调用
    返回 HTTP 2xx 的请求计一次；4xx 参数错误与 5xx 服务端错误不计费。语音转写单次音频不超过 60 秒，超出按每 60 秒折算一次。
    结算方式
    按小时汇总用量，次月 3 日前出账。账单金额精确到分，不足一分按一分计。
