用户服务 API

基于 REST 风格的用户管理接口。所有请求与响应均使用 JSON 编码（UTF-8）。

项目说明
Base URLhttps://api.example.com/v1
协议仅支持 HTTPS
Content-Typeapplication/json
时间格式ISO 8601，UTC，例如 2026-10-26T08:30:00Z

鉴权方式

API 使用 Bearer Token（OAuth 2.0 Client Credentials）鉴权。先用 client_id 和 client_secret 换取访问令牌，再在每个请求的 Authorization 头中携带该令牌。

1. 获取访问令牌

POST/oauth/token
请求
curl -X POST https://api.example.com/v1/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "client_credentials",
    "client_id": "YOUR_CLIENT_ID",
    "client_secret": "YOUR_CLIENT_SECRET",
    "scope": "users:read users:write"
  }'
响应 200
{
  "access_token": "eyJhbGciOiJSUzI1NiIs...",
  "token_type": "Bearer",
  "expires_in": 7200,
  "scope": "users:read users:write"
}

2. 在请求中携带令牌

Authorization: Bearer eyJhbGciOiJSUzI1NiIs...

权限范围（scope）

Scope说明适用接口
users:read读取用户信息用户列表、用户详情
users:write创建与修改用户创建用户、更新用户
令牌有效期为 expires_in 秒（默认 2 小时）。过期后接口返回 401，请重新获取令牌。
client_secret 只能保存在服务端，切勿写入前端代码或移动端安装包。

错误码

出错时返回对应的 HTTP 状态码，响应体格式统一：

{
  "error": {
    "code": "validation_failed",
    "message": "email 格式不正确",
    "request_id": "req_8f2a1c"
  }
}
状态码code含义
400bad_request请求格式错误
401unauthorized未携带令牌，或令牌无效 / 已过期
403forbidden令牌缺少所需 scope
404not_found资源不存在
409conflict资源冲突（如邮箱已被注册）
422validation_failed字段校验失败
429rate_limited请求过于频繁，参考 Retry-After 响应头
500internal_error服务端错误，请附上 request_id 联系我们

用户接口

用户对象字段：

字段类型说明
idstring用户唯一 ID，以 usr_ 开头
namestring用户名称
emailstring邮箱，全局唯一
rolestringadmin | member
statusstringactive | disabled
created_atstring创建时间
updated_atstring最后更新时间

获取用户列表

GET/users

分页返回用户列表。需要 scope：users:read

Query 参数
参数类型说明
page 可选integer页码，从 1 开始，默认 1
page_size 可选integer每页条数，1–100，默认 20
status 可选string按状态筛选：active / disabled
q 可选string按名称或邮箱模糊搜索
请求
curl "https://api.example.com/v1/users?page=1&page_size=2" \
  -H "Authorization: Bearer $TOKEN"
响应 200
{
  "data": [
    {
      "id": "usr_1001",
      "name": "张三",
      "email": "zhangsan@example.com",
      "role": "admin",
      "status": "active",
      "created_at": "2026-01-12T03:20:00Z",
      "updated_at": "2026-09-01T10:00:00Z"
    },
    { "id": "usr_1002", "...": "..." }
  ],
  "pagination": {
    "page": 1,
    "page_size": 2,
    "total": 57
  }
}

获取用户详情

GET/users/{id}

根据 ID 获取单个用户。需要 scope：users:read

Path 参数
参数类型说明
id 必填string用户 ID
请求
curl https://api.example.com/v1/users/usr_1001 \
  -H "Authorization: Bearer $TOKEN"
响应 200
{
  "id": "usr_1001",
  "name": "张三",
  "email": "zhangsan@example.com",
  "role": "admin",
  "status": "active",
  "created_at": "2026-01-12T03:20:00Z",
  "updated_at": "2026-09-01T10:00:00Z"
}

可能的错误：404 用户不存在。

创建用户

POST/users

创建新用户。需要 scope：users:write

Body 参数
字段类型说明
name 必填string1–64 个字符
email 必填string合法邮箱，不能与已有用户重复
password 必填string至少 8 位，需包含字母和数字；不会在响应中返回
role 可选string默认 member
请求
curl -X POST https://api.example.com/v1/users \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "李四",
    "email": "lisi@example.com",
    "password": "s3cretPass",
    "role": "member"
  }'
响应 201
{
  "id": "usr_1058",
  "name": "李四",
  "email": "lisi@example.com",
  "role": "member",
  "status": "active",
  "created_at": "2026-10-26T08:30:00Z",
  "updated_at": "2026-10-26T08:30:00Z"
}

可能的错误：409 邮箱已存在；422 字段校验失败。

更新用户

PATCH/users/{id}

部分更新用户信息，只需传入要修改的字段。需要 scope：users:write

Body 参数（均为可选，至少传一个）
字段类型说明
namestring1–64 个字符
emailstring新邮箱，不能与已有用户重复
rolestringadmin | member
statusstring设为 disabled 可停用用户
请求
curl -X PATCH https://api.example.com/v1/users/usr_1058 \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "role": "admin" }'
响应 200
{
  "id": "usr_1058",
  "name": "李四",
  "email": "lisi@example.com",
  "role": "admin",
  "status": "active",
  "created_at": "2026-10-26T08:30:00Z",
  "updated_at": "2026-10-26T09:12:45Z"
}

可能的错误：404 用户不存在；409 邮箱冲突；422 字段校验失败。
