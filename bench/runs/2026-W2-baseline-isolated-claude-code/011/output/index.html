常见问题

还有疑问？欢迎联系 support@sujie.example

下载的素材可以用于商业项目吗？

专业版和团队版下载的素材均可用于商业项目。专业版适用于个人或自由职业者的商业作品；若涉及企业品牌推广、广告投放或大批量印刷，请选择团队版的企业级授权。

会员到期后，已下载的素材还能继续使用吗？

可以。在会员有效期内下载的素材，其授权永久有效，到期后仍可在已完成的项目中继续使用。

可以随时升级或取消吗？

可以随时升级，差价按剩余天数折算。取消订阅后，会员权益将保留到当前计费周期结束，不会再自动续费。

支持哪些付款方式？

支持微信支付、支付宝、银联及主流国际信用卡。团队版还支持对公转账。

团队版可以中途增加成员吗？

可以，管理员可在后台随时添加席位，新增席位按剩余周期折算费用。
