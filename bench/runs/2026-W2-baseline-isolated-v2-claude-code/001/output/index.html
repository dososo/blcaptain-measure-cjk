Roasting Philosophy

我们相信的几件事

“好的烘焙不是给豆子加上味道，
而是把它本来的样子带出来。”
  1. 01

    小批量，慢火候

    每炉最多 12 公斤，烘焙师全程守在机器旁，根据每支豆子的密度与含水率随时调整火力和风门。

  2. 02

    为风味而烘，不为颜色

    我们不追求统一的深浅，而是为每支豆子找到最能体现产地特色的那条曲线——有时浅一点，有时深一点。

  3. 03

    新鲜，但不急

    每周只烘两次，出炉后静置养豆数日再上架，让二氧化碳充分释放，风味趋于稳定。

  4. 04

    和种植者站在一起

    优先与长期合作的庄园和小农合作社直接采购，价格高于市场均价，并在包装上标注每支豆子的来源。
