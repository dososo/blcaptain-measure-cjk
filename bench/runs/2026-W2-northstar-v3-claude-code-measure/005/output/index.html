科室介绍

常见病在本院就能处理，需要大型设备的检查，我们会帮你联系合作的专科医院。

  • 内科门诊

    呕吐、腹泻、咳嗽、食欲差等常见问题，配合血常规、生化和影像检查确诊。

  • 外科与绝育

    猫狗绝育、伤口缝合、肿物切除。术前做麻醉评估，术后可以留院观察一晚。

  • 预防保健

    幼宠疫苗、狂犬疫苗、体内外驱虫和年度体检，到期前会短信提醒。

  • 皮肤科

    掉毛、瘙痒、真菌和过敏。做皮肤刮片和伍德灯检查，制定洗护和用药方案。

  • 口腔科

    洗牙、拔牙和口臭问题。老年猫狗洗牙前会先做心肺和血液检查。

  • 影像与化验

    数字 X 光、B 超和血液化验，大部分结果当天出，医生当面讲解。
