烘焙理念

我们相信的几件小事

  1. 先尝生豆，再决定怎么烘

    每支新豆子到店，我们会用三条不同的曲线各烘一小锅，盲测之后再定下最终方案。同一个产区的豆子，今年和去年的烘法也可能不一样。

  2. 烘得浅一点，把产地的味道留下来

    单品豆大多停在浅烘到中烘之间。我们想让你喝出埃塞的花香、肯尼亚的莓果酸，而不是千篇一律的焦苦。

  3. 小批量，每周都新鲜

    每周四、五烘豆，每炉不超过 5 公斤。卖完就等下一炉，不囤货，也不提前烘好放着。

  4. 每一炉都留记录

    温度曲线、环境湿度、杯测分数都存档。你买到的每一袋豆子，我们都能说出它是哪一天、哪一炉烘出来的。

好的烘焙，是让人忘了烘焙这回事，只记得这杯咖啡。

—— 主理人 阿岩
