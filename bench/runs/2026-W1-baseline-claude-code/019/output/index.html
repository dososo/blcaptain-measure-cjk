接口

用户服务 REST API

本文档说明如何完成鉴权，以及如何创建、读取、更新、删除用户。所有请求与响应均使用 JSON，字符编码为 UTF-8。

基础信息

项值
Base URLhttps://api.example.com/v1
协议仅 HTTPS，HTTP 请求会被拒绝
Content-Typeapplication/json
时间格式ISO 8601，UTC，例如 2026-10-25T08:00:00Z
ID 格式字符串，前缀 usr_

鉴权

所有接口都需要 Bearer Token。先用 API Key 换取访问令牌（Access Token），之后每个请求在 Authorization 请求头中带上它。

第一步：获取访问令牌

POST/auth/token

请求

curl -X POST https://api.example.com/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{"api_key": "sk_live_xxxxxxxx", "api_secret": "xxxxxxxx"}'

响应 200

{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "Bearer",
  "expires_in": 3600
}

第二步：在请求头中携带令牌

Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

规则

项说明
有效期3600 秒；过期后重新调用 /auth/token
未携带 / 无效返回 401 unauthorized
权限不足返回 403 forbidden
限流每个令牌 60 次/分钟，超出返回 429，见响应头 Retry-After

不要把 API Key 或令牌放在 URL 查询参数中（如 ?token=），它们会进入服务器日志和浏览器历史。也不要在前端代码中硬编码 API Key。

错误码

出错时统一返回如下结构：

{
  "error": {
    "code": "validation_failed",
    "message": "email 格式不正确",
    "field": "email"
  }
}
HTTPcode含义
400validation_failed参数缺失或格式错误
401unauthorized令牌缺失、无效或过期
403forbidden无权操作该资源
404not_found用户不存在
409conflict邮箱已被注册
429rate_limited请求过于频繁
500internal_error服务端异常

创建用户

POST/users

新建一个用户，成功返回 201 Created 和完整的用户对象。

请求体

字段类型说明
emailstring必填邮箱，全局唯一
namestring必填显示名，1–50 字符
phonestring可选E.164 格式，如 +8613800000000
rolestring可选member（默认）或 admin

请求

curl -X POST https://api.example.com/v1/users \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"email": "lin@example.com", "name": "林青"}'

响应 201

{
  "id": "usr_8f2a1c",
  "email": "lin@example.com",
  "name": "林青",
  "phone": null,
  "role": "member",
  "created_at": "2026-10-25T08:00:00Z",
  "updated_at": "2026-10-25T08:00:00Z"
}

可能的错误：400 参数错误，409 邮箱已存在。

获取用户

GET/users/{id}

按 ID 读取单个用户。

路径参数

参数类型说明
idstring必填用户 ID，如 usr_8f2a1c

请求

curl https://api.example.com/v1/users/usr_8f2a1c \
  -H "Authorization: Bearer $TOKEN"

响应 200

{
  "id": "usr_8f2a1c",
  "email": "lin@example.com",
  "name": "林青",
  "phone": null,
  "role": "member",
  "created_at": "2026-10-25T08:00:00Z",
  "updated_at": "2026-10-25T08:00:00Z"
}

可能的错误：404 用户不存在。

更新用户

PATCH/users/{id}

部分更新：只修改请求体中出现的字段，未出现的字段保持不变。email 不可修改。

请求体

字段类型说明
namestring可选显示名，1–50 字符
phonestring | null可选传 null 表示清空
rolestring可选仅 admin 可修改

请求

curl -X PATCH https://api.example.com/v1/users/usr_8f2a1c \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"phone": "+8613800000000"}'

响应 200

{
  "id": "usr_8f2a1c",
  "email": "lin@example.com",
  "name": "林青",
  "phone": "+8613800000000",
  "role": "member",
  "created_at": "2026-10-25T08:00:00Z",
  "updated_at": "2026-10-25T09:12:40Z"
}

可能的错误：400 参数错误，403 无权修改 role，404 用户不存在。

删除用户

DELETE/users/{id}

删除指定用户，成功返回 204 No Content，无响应体。操作幂等：重复删除同一个已删除用户返回 404，不会产生其他副作用。

路径参数

参数类型说明
idstring必填用户 ID

请求

curl -X DELETE https://api.example.com/v1/users/usr_8f2a1c \
  -H "Authorization: Bearer $TOKEN"

响应 204

（无响应体）

删除不可恢复。需要 admin 角色，否则返回 403。
