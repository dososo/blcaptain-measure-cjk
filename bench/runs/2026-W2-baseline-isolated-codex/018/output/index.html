01

录入指纹

首次使用 / 添加成员

录入常用手指，让日常开门更方便。以下菜单名称仅为示例。

开始前：保持门处于打开状态，准备好管理员验证方式，并擦干手指和指纹识别区。

  1. 进入管理员设置

    唤醒门锁，按照本机说明书进入设置菜单，使用管理员密码、指纹或其他已授权方式完成验证。首次使用请先按说明书创建管理员。

  2. 选择添加指纹

    在菜单中找到类似 用户管理 → 添加用户 → 添加指纹 的选项，按提示选择成员与权限。

  3. 多次采集同一根手指

    将指腹自然贴合识别区，按语音或屏幕提示抬起、重新放下。每次略微调整角度，覆盖指腹中心和边缘，直到提示录入成功。

  4. 保持开门状态，测试识别

    退出设置后，用新录入的指纹多次测试。确认识别稳定、锁舌正常动作，再关门使用；请勿在锁舌伸出时强行关门。

使用小贴士可为常用成员录入另一根备用手指。指纹较浅或手指受伤时，使用已设置的其他开锁方式。
02

更换电池

低电量提示时

听到低电量提醒或看到电量不足提示，请及时处理。

干电池款

以电池仓标注为准，使用规定型号与数量的电池。

专用锂电池款

使用原厂或指定兼容电池，按说明书充电、更换。

  1. 开门后，找到室内侧电池仓

    保持门打开，准备好备用开锁方式。电池仓通常在室内面板上方，按标记滑开、按压或拧下螺丝后取下仓盖，勿强行撬开。

  2. 取出旧电池，装入匹配的新电池

    干电池请整组更换，按照仓内 ＋ / − 标记安装，勿混用新旧电池、不同品牌或不同类型。专用电池包请按说明书接好接口，勿拉扯线材。

  3. 装回仓盖，检查门锁状态

    确认电池固定、仓盖闭合，待门锁启动后测试指纹或密码开锁。若仍提示低电量，检查电池规格、方向与接触情况。

完全没电了？可使用机械钥匙；支持应急供电的型号，可按说明书连接指定电源，再用已授权方式开锁。应急接口不一定具备充电功能。
03

恢复出厂设置

请谨慎操作

适用于需要清除原有配置、重新初始化的情况。

重置可能清除所有已录入的开锁信息。
指纹、密码、卡片及本地设置等可能被删除，通常无法撤销。设备联网及账号绑定是否解除，取决于具体型号；转交门锁前请另行核实解绑要求。

  1. 保持门打开，确认管理员权限

    在门内操作，确保电量充足，并准备机械钥匙或说明书指定的备用方式。仅对你拥有或获授权管理的门锁执行重置。

  2. 查找本型号的重置方法

    部分型号通过管理员菜单中的“恢复出厂设置”操作，部分通过室内侧标注的 RESET 或初始化按键操作。请查阅本机说明书确认位置、验证方式和按键时长，勿猜测或随意长按。

  3. 确认重置，等待完成提示

    按本机语音、屏幕或说明书要求完成验证与确认。重置期间保持供电，直到门锁提示初始化完成。

  4. 重新设置管理员并测试

    立即按说明书设置新的管理员凭据，重新录入成员；需要联网的型号还应完成配网或绑定。保持门打开，确认设置完成并成功测试开锁后再关门。

你可能还想知道

指纹总是识别失败，怎么办？

先用柔软干布清洁识别区，保持手指洁净、无水渍，并用录入时的姿势完整贴合指腹。仍不稳定时可通过管理员菜单重新录入，或使用另一根已录入的手指。暂时无法识别时，请使用密码、机械钥匙等已配置的备用方式。

更换电池后，需要重新录入指纹吗？

多数门锁在正常更换电池后会保留已录入的用户信息，但时间、联网状态等可能需要检查，具体以本型号说明书为准。若更换后异常，请先检查电池和连接，不要直接恢复出厂设置。

忘记管理员密码，可以直接重置吗？

不同型号的重置验证要求不同，无法保证通过按键直接重置。请先尝试其他已授权的管理员验证方式，或通过品牌官方售后核验所有权后处理，避免反复尝试触发临时锁定。

多一份准备，多一份安心。

请将机械钥匙放在门外可安全取用的地方，妥善保管管理员凭据。
