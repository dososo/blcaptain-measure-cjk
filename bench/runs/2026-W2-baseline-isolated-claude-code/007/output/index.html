告别手工复制粘贴：用 Python 处理 Excel 报表的 5 个技巧

2026 年 10 月 25 日 阅读约 12 分钟 适用：pandas 2.x · openpyxl 3.1+

每到月底，总有人要把几十个部门交上来的表格合并、核对、汇总，再调好格式发给领导。 这些工作重复、易错，而且完全可以交给 Python。本文整理了我在实际项目中最常用的 5 个技巧， 从读取、清洗、汇总到导出和美化，覆盖一份报表的完整生命周期。

开始之前，确保环境里有这两个库（xlsx 读写都依赖 openpyxl 引擎）：

shell
pip install pandas openpyxl

01批量合并多个文件，并保留来源

最常见的需求：一个文件夹里有 销售_北京.xlsx、销售_上海.xlsx……结构相同，需要合成一张总表。 关键是别忘了记录每行数据来自哪个文件，否则后面核对时无从查起。

merge_files.py
from pathlib import Path
import pandas as pd

src_dir = Path("./data/monthly")
frames = []

for file in sorted(src_dir.glob("销售_*.xlsx")):
    # 跳过 Excel 打开时生成的临时锁文件 ~$xxx.xlsx
    if file.name.startswith("~$"):
        continue
    df = pd.read_excel(file)
    df["来源文件"] = file.stem               # 记录来源
    df["区域"] = file.stem.split("_")[1]     # 从文件名提取区域
    frames.append(df)

total = pd.concat(frames, ignore_index=True)
print(f"共合并 {len(frames)} 个文件，{len(total)} 行数据")

如果一个工作簿里有多个结构相同的 Sheet（比如 1 月到 12 月），用 sheet_name=None 一次读出全部，返回的是一个 {表名: DataFrame} 字典：

python
sheets = pd.read_excel("2026年销售.xlsx", sheet_name=None)

total = pd.concat(
    [df.assign(月份=name) for name, df in sheets.items()],
    ignore_index=True,
)
💡 小提示 pd.concat 要在循环外调用一次，而不是在循环里反复拼接。后者每次都会复制全部数据，文件一多速度会明显变慢。

02读取时就把类型和脏数据处理好

Excel 是"所见非所得"的重灾区：员工编号 00123 被读成整数 123， 金额列混进了 "—" 或 "待定"，表头上面还有两行标题。与其读完再修，不如在 read_excel 时一步到位。

clean.py
df = pd.read_excel(
    "员工绩效.xlsx",
    skiprows=2,                          # 跳过顶部的大标题行
    usecols="A:F",                       # 只读需要的列，速度更快
    dtype={"员工编号": str, "手机号": str},  # 保留前导零
    na_values=["—", "-", "待定", "N/A"],  # 这些都视为缺失值
    parse_dates=["入职日期"],
)

# 清理列名中的空格和换行（合并单元格表头的常见问题）
df.columns = df.columns.str.strip().str.replace("\n", "", regex=False)

# 金额列：去掉千分位逗号和货币符号，再转数字
df["奖金"] = pd.to_numeric(
    df["奖金"].astype(str).str.replace(r"[¥,\s]", "", regex=True),
    errors="coerce",                     # 转换失败的变成 NaN，而不是报错
)

# 去掉整行为空的记录，按员工编号去重
df = df.dropna(how="all").drop_duplicates(subset="员工编号", keep="last")

清洗完以后建议顺手做个检查，把问题行单独导出给业务方确认，而不是悄悄丢掉：

python
bad_rows = df[df["奖金"].isna()]
if not bad_rows.empty:
    bad_rows.to_excel("待确认数据.xlsx", index=False)
    print(f"⚠️ 有 {len(bad_rows)} 行奖金无法识别，已导出待确认")

03用 pivot_table 代替 Excel 数据透视表

汇总报表的核心就是"按什么维度、对什么指标、做什么计算"。pivot_table 一行就能复现 Excel 透视表， 而且可以加总计行、处理缺失组合，下个月换份数据重跑即可。

pivot.py
summary = pd.pivot_table(
    total,
    index="区域",
    columns="产品线",
    values="销售额",
    aggfunc="sum",
    fill_value=0,          # 某区域没有某产品时填 0 而不是 NaN
    margins=True,          # 添加"总计"行和列
    margins_name="总计",
)

# 按总计从高到低排序（总计行保持在最后）
body = summary.drop(index="总计").sort_values("总计", ascending=False)
summary = pd.concat([body, summary.loc[["总计"]]])

如果需要同时计算多个指标（比如销售额求和、订单数计数、客单价求平均），用 groupby + 具名聚合可读性更好：

python
kpi = (
    total.groupby("区域")
    .agg(
        销售额=("销售额", "sum"),
        订单数=("订单号", "nunique"),
        客单价=("销售额", "mean"),
    )
    .assign(占比=lambda d: d["销售额"] / d["销售额"].sum())
    .sort_values("销售额", ascending=False)
    .round(2)
)
Excel 操作pandas 写法
数据透视表pd.pivot_table(...)
分类汇总df.groupby(...).agg(...)
VLOOKUPdf.merge(other, on="键", how="left")
筛选df.query("销售额 > 10000")
删除重复项df.drop_duplicates(...)

04一次写出多个 Sheet 的工作簿

直接调用 df.to_excel("a.xlsx") 每次都会覆盖整个文件。要把明细、汇总、KPI 放进同一个工作簿的不同 Sheet， 需要用 ExcelWriter 作为上下文管理器：

export.py
output = "2026年10月销售报表.xlsx"

with pd.ExcelWriter(output, engine="openpyxl") as writer:
    kpi.to_excel(writer, sheet_name="KPI概览")
    summary.to_excel(writer, sheet_name="区域x产品线")
    total.to_excel(writer, sheet_name="明细数据", index=False)

    # 同一个 Sheet 里放多张表：用 startrow / startcol 指定位置
    top10 = total.nlargest(10, "销售额")
    top10.to_excel(writer, sheet_name="KPI概览", startrow=len(kpi) + 3, index=False)

如果要往已有的工作簿里追加或替换某个 Sheet（比如模板文件里已有封面页），使用追加模式：

python
with pd.ExcelWriter(
    "报表模板.xlsx",
    engine="openpyxl",
    mode="a",                    # 追加模式
    if_sheet_exists="replace",   # 同名 Sheet 直接替换
) as writer:
    summary.to_excel(writer, sheet_name="本月汇总")
⚠️ 注意 运行脚本前要先关闭 Excel 里打开的同名文件，否则在 Windows 上会抛出 PermissionError。

05用 openpyxl 自动美化：列宽、格式、条件高亮

pandas 导出的表格是"裸"的：列宽挤在一起、金额没有千分位、表头也不醒目。领导打开第一眼看到的就是格式， 这一步值得自动化。下面这个函数可以复用在任何导出的 Sheet 上：

beautify.py
from openpyxl import load_workbook
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side
from openpyxl.formatting.rule import ColorScaleRule, CellIsRule
from openpyxl.utils import get_column_letter


def beautify_sheet(ws, money_cols=(), pct_cols=()):
    header_fill = PatternFill("solid", fgColor="1D7A55")
    thin = Side(style="thin", color="D0D7DE")

    # 1. 表头：加粗、白字、绿底、居中
    for cell in ws[1]:
        cell.font = Font(bold=True, color="FFFFFF")
        cell.fill = header_fill
        cell.alignment = Alignment(horizontal="center", vertical="center")

    # 2. 冻结首行 + 开启筛选
    ws.freeze_panes = "A2"
    ws.auto_filter.ref = ws.dimensions

    # 3. 根据内容自动调整列宽（中文字符按 2 个宽度计算）
    for col_idx, column in enumerate(ws.columns, start=1):
        max_len = max(
            sum(2 if ord(ch) > 127 else 1 for ch in str(c.value or ""))
            for c in column
        )
        ws.column_dimensions[get_column_letter(col_idx)].width = min(max_len + 4, 50)

    # 4. 数字格式 + 细边框
    headers = {c.value: c.column_letter for c in ws[1]}
    for row in ws.iter_rows(min_row=2):
        for cell in row:
            cell.border = Border(top=thin, bottom=thin, left=thin, right=thin)
    for name in money_cols:
        for cell in ws[headers[name]][1:]:
            cell.number_format = "#,##0.00"
    for name in pct_cols:
        for cell in ws[headers[name]][1:]:
            cell.number_format = "0.0%"


wb = load_workbook("2026年10月销售报表.xlsx")
ws = wb["KPI概览"]
beautify_sheet(ws, money_cols=["销售额", "客单价"], pct_cols=["占比"])

# 5. 条件格式：销售额做三色色阶，占比低于 5% 标红
last = ws.max_row
col = {c.value: c.column_letter for c in ws[1]}
ws.conditional_formatting.add(
    f"{col['销售额']}2:{col['销售额']}{last}",
    ColorScaleRule(start_type="min", start_color="F8696B",
                   mid_type="percentile", mid_value=50, mid_color="FFEB84",
                   end_type="max", end_color="63BE7B"),
)
ws.conditional_formatting.add(
    f"{col['占比']}2:{col['占比']}{last}",
    CellIsRule(operator="lessThan", formula=["0.05"],
               font=Font(color="C00000", bold=True)),
)

wb.save("2026年10月销售报表.xlsx")

条件格式是以 Excel 规则的形式写入的，而不是把颜色"刷死"在单元格上。也就是说，业务同事之后手动修改了数值， 颜色会跟着自动更新——这和在 Excel 里手动设置的效果完全一样。

💡 进阶 数据量很大（几十万行）且只需写不需读时，可以换用 xlsxwriter 引擎，写入速度更快，格式和图表 API 也更丰富； 代价是它不能读取或修改已有文件。

小结：把它们串成一条流水线

这 5 个技巧恰好对应报表处理的 5 个阶段，组合起来就是一个可以每月一键重跑的脚本：

  • 合并：glob + concat，记得保留来源列；
  • 清洗：在 read_excel 里指定 dtype、na_values，问题行导出确认；
  • 汇总：pivot_table 与具名聚合 agg；
  • 导出：ExcelWriter 写多 Sheet，mode="a" 追加到模板；
  • 美化：openpyxl 设置表头、列宽、数字格式和条件格式。

下一步，你可以把脚本挂到定时任务上，或者再加几行代码用邮件自动发送——从此月底不再加班。
