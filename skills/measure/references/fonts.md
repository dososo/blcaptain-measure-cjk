# 中文字体：怎么选、能不能用

> **本文不是法律意见。** 授权条款可能变化，以官方最新原文为准。下表的结论来自 2026-10-25 对各字体官方授权原文的核验，每一条都能用 `measure-cjk fonts "<字体名>"` 查到原文链接。

## 1. 选字体栈：决策树

1. **先定宋体系还是黑体系，不要混用。**
   - 黑体系（无衬线）：界面、产品页、卡片、大多数网页。
   - 宋体系（衬线）：长文、文学、报刊风格的页面。
   - 楷体：只用于少量点缀，比如引文、签名，不做正文。
2. **同一页最多两个中文字族**，比如「标题一个、正文一个」。
3. **先写西文字体，再写中文字体，最后写通用族**，让英文和数字用西文字体显示。
4. **决定字体来源：**
   - 只写字体名、不提供字体文件，就是调用访客电脑上已有的字体。🟢🔵🟡 档都可以这样用。
   - 要用 `@font-face` 自托管字体文件，只能用 🟢 档。

### 常用字体栈

```css
/* 黑体系，系统字体 */
font-family: "Inter", "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;

/* 宋体系，系统字体 */
font-family: "Source Serif 4", "Noto Serif SC", "Songti SC", "SimSun", serif;

/* 自托管 webfont（只能是 🟢 档，首选 Noto CJK） */
@font-face { font-family: "Noto Sans SC"; src: url("fonts/NotoSansSC-subset.woff2") format("woff2"); font-display: swap; }
```

## 2. 四档

| 档位 | 含义 | 自托管 webfont | 出商用图片 |
|---|---|---|---|
| 🟢 可嵌入 | 开源字体（OFL） | 可以 | 可以 |
| 🔵 可出图 | 厂商免费商用字体 | 不可以，或者原文没写清 | 可以 |
| 🟡 只能调用系统字体 | 随操作系统提供的字体 | 不可以 | 看具体字体 |
| 🔴 商用授权 | 需要购买 | 不可以 | 需要购买 |
| ❔ 未知 | 授权表里没有，或者原文没写清 | 不要用 | 不要用 |

**校验器的判定按字段，不按档位：**
- 自托管看 `webfont_self_host`，只有为 `true` 才放行。
- 出图看 `commercial_image`，只有为 `true` 才放行。

## 4. 四个和常识不一样的地方

1. **「免费商用」不等于「能做网页字体」。** 普惠体、HarmonyOS Sans、MiSans、OPPO Sans 都可以出商用图片；其中普惠体、OPPO Sans 不能自托管成 webfont，HarmonyOS Sans、MiSans 原文没写清能不能，校验器一律按「不能确认」报错。
2. **「OFL 开源」不等于「子集化后可以照用原名」。** 思源、霞鹜文楷、得意黑都有保留字体名，子集化后要改掉字体内部的名称表。
3. **有的免费授权可以被收回。** HarmonyOS Sans 和 MiSans 的授权写明可撤销，而且要求署名。
4. **方正的「免费字体」只对「发布使用」免费。** 嵌入网站仍然需要授权。

<a id="f03"></a>
## F03 自托管 webfont 的授权（error / warn）

页面里每一个 `@font-face` 都会按字体名和文件名去查授权表：
- 只写了 `local()` → 不检查（用的是访客电脑上的字体）。
- 有本地或相对路径的 `url()`（自托管）且命中的条目 `webfont_self_host` 不为 `true` → error。
- 只有远程 URL（CDN 引用）且条目不是 🟢 → warn：授权表没有记录 CDN 引用是否允许（原文未明确）。
- 不在表里 → warn `F-UNKNOWN`，提示先查官方原文。

<a id="f04"></a>
## F04 查询授权

```bash
node <measure-cjk 仓库>/packages/cli/bin/measure-cjk.js fonts "阿里巴巴普惠体"
```

输出档位、两个关键字段、是否需要署名、授权能否撤销、原文链接和核验日期。

<a id="f05"></a>
## F05 webfont 体积预算和子集化改名（P1）

首屏中文字体的传输体积建议不超过 300 KB。子集化工具（比如 cn-font-split，Apache-2.0）安装时会下载原生二进制，本项目只在文档里提到它，不作为依赖。

<a id="f06"></a>
## F06 出图场景（W2）

导出小红书卡片时，只允许 `commercial_image` 为 `true` 的字体。
- 微软雅黑原文允许出图，但只能从本机系统字体调用，不能拷到别的目录。
- 苹方能不能商用出图，原文没写清，按不允许处理。
