功能介绍

从记一笔账到交给会计，中间的事合账都帮你做了。

报销不再靠微信群接龙

成员拍一张发票就能提交报销，金额、日期、抬头自动识别。负责人在手机上点一下就能批，批完自动记进账本，谁报了多少、还差谁没报，一目了然。

  1. 拍票提交支持纸质发票、电子发票和小票照片。
  2. 负责人审批可以设置金额上限，超出才需要审批。
  3. 自动入账审批通过后按类别记账，附件一并归档。
多人共用一个账本
按成员分配权限：有人只能记账，有人能看报表，有人能审批。每一次修改都有记录。
按项目、按客户分账
给每笔收支打上项目标签，随时看某个项目赚了多少、花了多少。
预算提醒
给差旅、采购等类别设月度预算，快超支时提前通知负责人。
一键导出给会计
导出 Excel 明细和发票压缩包，格式按代账公司常用模板整理好。
