每到月底，复制、粘贴、筛选、求和……熟悉的流程又来一遍。其实，只需要几行 Python，就能把这些重复操作变成一套可复用的报表流程。

这篇文章以一份销售明细为例，分享 5 个可以直接用到日常工作中的技巧。我们会从读取数据开始，一步步得到一份整洁的汇总报表。

⌘
开始之前

示例使用 Python 3、pandas 和 openpyxl。运行环境需已安装这两个库；下方代码按顺序执行。

import pandas as pd

01

精准读取，只取需要的数据

不用把整张工作簿都搬进内存。指定工作表、列名和数据类型，读取的第一步就能更准确，也能减少后续清洗的工作量。

Python 01_read.py
import pandas as pd

df = pd.read_excel(
    "sales.xlsx",
    sheet_name="销售明细",
    usecols=["订单号", "日期", "地区", "销售额"],
    dtype={"订单号": "string"},
    engine="openpyxl",
)
print(df.head())

小提示dtype 能保留文本订单号的前导零；已被 Excel 存成数字的零，无法靠读取时指定类型恢复。

02

统一格式，让脏数据无处藏身

空值、重复订单、带千位分隔符的金额，都可能影响统计结果。先规范格式，再把无效记录单独保留，方便回溯和核对。

Python 02_clean.py
# 清理空格，统一金额和日期格式
df["订单号"] = df["订单号"].str.strip().replace("", pd.NA)
df["地区"] = df["地区"].astype("string").str.strip()
df["地区"] = df["地区"].replace("", pd.NA)
amount = df["销售额"].astype("string").str.replace(",", "", regex=False)
df["销售额"] = pd.to_numeric(amount, errors="coerce")
df["日期"] = pd.to_datetime(df["日期"], errors="coerce")

invalid = df.isna().any(axis=1)
rejected = df.loc[invalid].copy()
valid = df.loc[~invalid].copy()
duplicates = valid.loc[valid.duplicated("订单号", keep="last")]
clean = valid.drop_duplicates("订单号", keep="last")

注意边界示例假设一笔订单只有一行，并保留文件中最后一条有效记录。若订单包含多个商品，请使用订单号与商品编号等组合键。

03

一张透视表，看清每月销售表现

想同时比较月份和地区？用 pivot_table 把明细转换为二维汇总表，省去手动拖拽字段的步骤。

Python 03_pivot.py
clean = clean.copy()
clean["月份"] = clean["日期"].dt.strftime("%Y-%m")

summary = clean.pivot_table(
    index="月份",
    columns="地区",
    values="销售额",
    aggfunc="sum",
    fill_value=0,
    margins=True,
    margins_name="合计",
)
print(summary)

04

合并多张表，补齐业务信息

销售明细里只有地区，负责人却在另一张表里。使用左连接，为每一条销售记录补充对应负责人，同时保留所有销售明细。

Python 04_merge.py
# 也可以从另一份 Excel 中读取这张对应表
owners = pd.DataFrame({
    "地区": ["华东", "华南"],
    "负责人": ["林晨", "陈悦"],
})
report = clean.merge(
    owners, on="地区", how="left", validate="many_to_one"
)
report["负责人"] = report["负责人"].fillna("待确认")

少踩一个坑validate="many_to_one" 会检查对应表的地区是否唯一，避免重复匹配导致明细行数和销售总额膨胀。

05

一次导出，交付一份好读的报表

把明细、汇总和待核对数据写进同一个工作簿，再加上表头颜色、冻结窗格与金额格式。让自动化的最后一步，也照顾到阅读体验。

Python 05_export.py
from openpyxl.styles import Font, PatternFill
from openpyxl.utils import get_column_letter

with pd.ExcelWriter("sales_report.xlsx", engine="openpyxl") as writer:
    report.to_excel(writer, sheet_name="销售明细", index=False)
    summary.to_excel(writer, sheet_name="月度汇总")
    rejected.to_excel(writer, sheet_name="无效记录", index=False)
    duplicates.to_excel(writer, sheet_name="重复记录", index=False)

    for ws in writer.book.worksheets:
        ws.freeze_panes = "B2"
        for cell in ws[1]:
            cell.font = Font(bold=True, color="FFFFFF")
            cell.fill = PatternFill("solid", fgColor="7060AE")
            letter = get_column_letter(cell.column)
            ws.column_dimensions[letter].width = 20

        for row in ws.iter_rows(min_row=2):
            for cell in row:
                header = ws.cell(1, cell.column).value
                if header == "销售额" or (
                    ws.title == "月度汇总" and cell.column > 1
                ):
                    cell.number_format = "#,##0.00"
                elif header == "日期":
                    cell.number_format = "yyyy-mm-dd"

交付前检查运行后会生成 sales_report.xlsx，同名文件会被覆盖。先核对汇总金额，再处理无效记录与重复记录。
