常见问题

忘记密码怎么办？
在 SSO 登录页点击“忘记密码”通过手机验证码重置；无法自助时联系 IT 服务台。
第一周没有具体任务正常吗？
很正常。第一周以熟悉环境、开通权限和学习为主，可以主动找主管或 Buddy 要一些入门任务。
上下班需要打卡吗？
请在即时通讯工具的考勤应用中打卡，具体规则见 HR 系统中的《考勤管理制度》。
试用期多长？如何转正？
以劳动合同约定为准。转正前主管会与你进行评估面谈，请提前与主管对齐试用期目标。
如对本指南有疑问或建议，请联系 HR 部门。祝你工作顺利！🎉
