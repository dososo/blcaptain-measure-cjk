购买须知

  1. 所有课程需要在小程序提前预约，开课前 2 小时可以免费取消。
  2. 预约后未到且没有取消，次卡扣除 1 次；月卡和年卡记 1 次爽约，一个月内爽约 3 次，暂停预约 7 天。
  3. 次卡、月卡和年卡均从第一次上课当天开始计算有效期，购买后 90 天内未使用的，自动开卡。
  4. 会籍限本人使用，不能转让；10 次卡带朋友同上的情况除外。
  5. 孕期、术后恢复期或有慢性疾病的会员，请在上课前告诉老师。

常见问题

完全没练过，可以直接上团课吗？

可以。课表里标着“入门”的课程适合零基础，建议先从哈他和阴瑜伽开始。

次卡用完了，能升级成月卡吗？

次卡有效期内，可以补差价升级为月卡或年卡，已经用掉的次数按每次 ¥128 折算。

买了没时间来，可以退款吗？

购买后 7 天内且未开卡，可以全额退款。开卡后不退款，月卡和年卡可以按规则请假。

需要自己带什么？

穿方便活动的衣服就行。瑜伽垫和毛巾都由工作室提供，也可以带自己的垫子。
