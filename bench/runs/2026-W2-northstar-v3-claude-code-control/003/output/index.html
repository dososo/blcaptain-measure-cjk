常见问题

还有疑问？直接加招新负责人微信问我们。

我没有自己的车，可以参加吗？

可以。体验阶段允许骑共享单车参加绿色组和技巧夜；我们也会在群里分享入门车的选购建议。

跟不上大部队怎么办？

每组都有收尾队员陪骑，路线设有固定集合点。实在体力不支可以随时由收尾陪同提前结束。

年龄有限制吗？

18 岁以上可独立报名；14–17 岁需监护人陪同参加，且仅限绿色组。

会员费都用在哪里？

主要用于活动意外险、急救包与备胎等公共装备，账目每季度在群内公开。
