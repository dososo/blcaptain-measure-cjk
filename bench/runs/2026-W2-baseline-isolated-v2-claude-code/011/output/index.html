常见问题

还有疑问？欢迎联系客服

会员到期后，已下载的素材还能继续使用吗？

可以。会员期间下载的素材，其授权永久有效，到期后已完成的作品无需下架。

可以随时升级或降级方案吗？

可以随时升级，剩余时长会按比例折算抵扣新方案费用；降级将在当前计费周期结束后生效。

个人商用和企业商用有什么区别？

个人商用适用于自由职业者以个人名义承接的项目；以公司名义使用、或用于公司自有品牌宣传，需要企业商用授权（团队版）。

如何申请退款？

首次开通付费会员 7 天内，且下载量不超过 20 个，可在「账户设置 → 订单」中一键申请全额退款。

团队版超过 50 人怎么办？

50 人以上的团队可联系商务获取企业定制报价，支持私有化素材库、SSO 单点登录与合同采购。
