少记命令，多做事情

从这里，开始 just。

把冗长的命令收进一个文件，用简单的名字运行它们。
只需几分钟，让项目里的日常任务井井有条。

约 5 分钟面向命令行使用者跨平台
❯_

一个 justfile，统一项目入口。
just 是一个命令运行器。安装一次，在每个项目中复用你的工作习惯。

01

安装 just

选择你的操作系统，在终端中执行安装命令。

Homebrew
$brew install just

需要先安装 Homebrew。其他安装方式见官方安装指南 ↗。

✓

安装后运行 just --version，显示版本号即表示安装成功。

02

配置你的项目

在项目根目录新建 justfile，给常用任务起个简短的名字。
以下以已有的 Node.js 项目为例，需已配置 dev 和 test 脚本。

▤ justfile
# 启动开发服务
dev:
    npm run dev

# 运行项目测试
test:
    npm test
i

小提示
每个任务的命令需要缩进，示例使用 4 个空格。just 会从当前目录向上查找 justfile，在项目子目录中也能运行。

03

记住这三个命令

保存配置后，在项目目录打开终端，试试你的新工作流。

01 /

查看可用任务

列出任务名称和注释，随时查阅。

just --list
02 /

启动开发服务

运行配置中的 dev 任务。

just dev
03 /

运行项目测试

运行配置中的 test 任务。

just test

dev 和 test 是本页配置的任务名，你也可以按项目需要自行命名。
