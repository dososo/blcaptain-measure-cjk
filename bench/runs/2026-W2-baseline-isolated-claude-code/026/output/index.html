打工人自救指南 ☀️

上班族
10分钟早餐

不早起也能吃好 · 4 个做法闭眼抄

  1. 🥪

    鸡蛋芝士吐司

    ⏱ 6min

    吐司中间压个坑 → 打入鸡蛋 → 撒芝士，空气炸锅 180℃ 烤 6 分钟。

  2. 🥣

    隔夜燕麦杯

    ⏱ 3min

    前一晚燕麦 + 牛奶 + 酸奶装罐冷藏，早上铺香蕉、蓝莓直接带走。

  3. 🍳

    番茄鸡蛋面

    ⏱ 10min

    番茄炒出汁加水，下挂面，打个蛋花，撒葱花和一点生抽。

  4. 🌯

    手抓饼卷一切

    ⏱ 5min

    速冻手抓饼煎至金黄，卷生菜、火腿、煎蛋，挤点番茄酱。

💡 小tips：前一晚把食材备好，早上更从容 记得收藏 ⭐
