常见问题

忘记密码或账号被锁定怎么办？

在 SSO 登录页点击「忘记密码」用手机号自助重置；如果仍无法登录，联系 IT 服务台。

第一周需要打卡吗？

需要。OA 账号开通后即可使用企业 IM 或 OA 打卡；开通前的考勤由 HR 统一处理。

系统权限不够用怎么申请？

在 IT 服务台提交「权限申请」工单，写明系统名称和用途，经直属上级审批后开通。

试用期有多长？怎么考核？

以劳动合同约定为准。试用期目标会在第 2 天与上级 1 对 1 时确定，期满前进行转正评估。
